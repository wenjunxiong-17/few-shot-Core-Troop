# results/ssl_maml —— 半监督信号注入位置实验的证据文件

本目录是 `ssl_maml/` 模块的实验产物，**每个数字都能直接重跑复现**。
`exp1` / `exp1b` 用合成数据，**不需要任何外部文件**；
`exp2` / `exp5` 需要 `data/water_dataset.mat`（版权原因不入库，获取方式见 `ssl_maml/README.md` 第 4 节）。

## 文件清单

| 文件 | 产出命令 | 内容 |
|---|---|---|
| `exp1_synth.json` | `python ssl_maml/experiments/exp1_synth.py` | 三种注入位置对比：7 个元训练主干 × 9 个评测方法 × 400 个测试任务 |
| `exp1b_alpha_sweep.json` | `python ssl_maml/experiments/exp1b_alpha.py` | (α, m) 扫描 + 冻结教师对照 |

## exp1_synth · MAML 二阶主干（准确率 %，400 个测试任务）

同一个 MAML 主干，只改**半监督项放在哪一步**：

| 位置 | 评测方法 | 准确率 | 相对纯监督 |
|---|---|---|---|
| —（基线） | `sup` 纯监督适应 | 75.86 ± 0.62 |  |
| ① 内层 | `sup_ent` 熵最小化 | 63.05 ± 0.61 | **-12.81** |
| ① 内层 | `sup_proto` 原型蒸馏 | 71.64 ± 0.69 | **-4.22** |
| ① 内层 | `sup_lp` LP 蒸馏 | 65.96 ± 0.71 | **-9.90** |
| ③ 适应之后 | `sup_then_lp` 标签传播 | 82.64 ± 0.58 | **+6.78** |
| ③ 适应之后 | `sup_then_st` 自训练 | 80.58 ± 0.59 | **+4.72** |

**增益的来源**（同一批评测方法，只换元训练主干）：

|---|---|---|---|
| 随机初始化 | 31.19 | 31.06 | **-0.13** |
| 联合预训练（不元学习） | 25.37 | 25.23 | **-0.14** |
| **MAML 二阶** | 75.86 | 82.64 | **+6.78** |
| FOMAML 一阶 | 78.94 | 81.30 | **+2.36** |

起点是随机初始化或普通预训练时，第三段增益 ≈ 0 —— **标签传播不生产信息，只是把好表示里隐含的结构读出来。**

**元训练阶段加半监督的对照**（评测时都用纯监督适应）：

| 元训练主干 | `sup` | 相对纯 MAML |
|---|---|---|
| 纯 MAML | 75.86 |  |
| MAML + 熵最小化（加在元训练内层） | 79.44 | **+3.58** |
| MAML + 原型蒸馏（同上） | 54.34 | **-21.52** |
| MAML + LP 蒸馏（同上） | 42.23 | **-33.63** |

`raw_lp`（不学习、直接在原始输入上做标签传播）：**31.33%** —— 说明表示本身没学好时，图传播读出来的是噪声。

## exp5 · 真实水数据（USGS 37 站 × 705 天 × 11 指标，次日 pH 回归）

MSE **越低越好**。`pl_reg` = Pseudo-Label + EMA 教师（推荐方法）。

| 设定 | 纯监督 `sup` | **`pl_reg`** | 相对 | `paired_d`（配对差） | 源域选中 λ |
|---|---|---|---|---|---|
| 随机站点划分 K=10 | 0.3783 | **0.2991** | **-20.9%** | -0.0792 ± 0.0165 | 1 |
| 随机站点划分 K=30 | 0.3871 | **0.2936** | **-24.1%** | -0.0935 ± 0.0459 | 1 |
| 空间划分 K=30 | 0.2829 | **0.2496** | **-11.8%** | -0.0333 ± 0.0066 | 1 |

**源域 λ 网格搜索选出的 λ**（`sup` 不涉及 SSL，λ 恒为 0；FixMatch / VAT 被搜出的最优 λ 是 0，即「别用」）：

| 方法 | 选中的 λ |
|---|---|
| `sup` | 0 |
| `pl_reg` | 1 |
| `pi_reg` | 0 |
| `vat_reg` | 0 |
| `manifold` | 0.1 |

## exp2 · 真实水数据 · 三段式（随机站点划分 K=10）

MSE，越低越好。元训练站点 25 个 / 元测试站点 12 个。

**各主干下的「适应之后」增益**（同一批评测、同一批 K 个标签）：

| 元训练主干 | `sup` 纯监督适应 | `sup_then_lp` | `sup_then_st` |
|---|---|---|---|
| 随机初始化 | 0.9089 | 0.7726 | 0.7474 |
| 联合预训练 | 1.0518 | 0.7726 | 0.6958 |
| MAML 二阶 | 0.4004 | 0.7726 | 0.4273 |
| MAML+内层流形正则 | 0.9452 | 0.7726 | 0.8872 |
| MAML+内层 LP 蒸馏 | 0.8889 | 0.7726 | 0.7866 |

**MAML 二阶主干下的全部方法**：

| 方法 | MSE | 说明 |
|---|---|---|
| `oracle_ridge` | 0.2649 ± 0.0797 | oracle（不可达上界参考） |
| `global_ridge` | 0.3569 ± 0.0692 | 全局岭回归 |
| `sup` | 0.4004 ± 0.0858 | MAML 纯监督适应 |
| `manifold` | 0.4021 ± 0.0861 | 内层加流形正则 |
| `sup_then_sthead` | 0.4073 ± 0.0925 | 适应后自训练（只调头部） |
| `sup_then_st` | 0.4273 ± 0.0945 | 适应后自训练 |
| `sup_then_lp_seeded` | 0.4403 ± 0.0911 | 同上（支持集播种） |
| `ridge` | 0.4865 ± 0.0865 | 逐任务岭回归 |
| `sup_then_da` | 0.4884 ± 0.0921 | 适应后数据增强 |
| `sup_then_lp_feat` | 0.5243 ± 0.1103 | 同上（特征空间） |
| `lpdistill` | 0.6189 ± 0.1006 | 内层加 LP 蒸馏 |
| `sup_then_lp` | 0.7726 ± 0.1156 | 适应后标签传播 |
| `support_mean` | 0.8787 ± 0.1110 | 只用支持集均值 |

**怎么读这张表（重要）**：`sup_then_lp` 是在**原始 11 维协变量**上做图传播（不经过主干特征），所以它的数值不随元训练主干变化；`sup_then_st` 用的是**当前模型给出的硬伪标签，没有滞后教师**。

这两个朴素版本在真实水数据上**都不如纯监督适应**（0.7726 / 0.4273 对 0.4004）。这恰好是 `exp5` 那条工程发现的直接证据：**标量回归下自训练必须用滞后的 EMA 教师** —— 换成 EMA 教师之后（`exp5` 的 `pl_reg`），MSE 从 0.3871 降到 0.2936（**-24.1%**）。
