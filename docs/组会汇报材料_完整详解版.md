## 术语速查表（看不懂任何地方回来查这里）

| 术语 | 英文 | 白话解释 |
|---|---|---|
| **任务 / episode** | task / episode | 一次小样本学习问题，比如"5 个类各给 1 个样本，学会区分这 5 类"。**一局游戏** |
| **支持集** | support set | 这一局里**有标签**的少量样本，用来"适应"这局 |
| **查询集** | query set | 同一局里**另一批有标签**样本，只用来打分（算元损失） |
| **无标签池** | unlabeled pool | 只有输入、没有答案的数据 |
| **内循环 / 适应** | inner loop / adaptation | 拿支持集做几步梯度下降，得到**只属于这局**的参数 $\theta'$ |
| **外循环 / 元更新** | outer loop / meta-update | 用所有局的成绩反过来更新**所有局共用的起点** $\theta$ |
| **初始化** | initialization | 一个"离所有任务的好答案都很近"的起点 |
| **元梯度** | meta-gradient | 对共享起点 θ 求导、在适应后的 θ′ 处取值。因为 θ′ 本身含 θ，求导要穿过"梯度"这一层 |
| **二阶 / HVP** | second-order / Hessian-vector product | 上面那个"穿过梯度求导"具体要做的事 |
| **一阶近似 FOMAML** | first-order MAML | 把二阶项直接丢掉，省一次反传 |
| **伪标签** | pseudo-label | 模型自己预测的标签，冒充真标签用 |
| **置信度阈值 $\tau$** | confidence threshold | 只采信"模型有把握"的伪标签，其余丢掉 |
| **课程** | curriculum | 早期少用无标签数据、后期放开的节奏 |
| **熵** | entropy | 混乱程度。`[1,0,0]` 熵为 0（最确定）；`[0.33,0.33,0.33]` 熵最大（瞎猜） |
| **熵最小化** | entropy minimization | 逼模型输出更确定（分布更接近 one-hot） |
| **退化解** | degenerate solution | 损失很低但没意义的解，比如"所有点都推给同一类" |
| **确认偏误** | confirmation bias | 错误的伪标签被反复强化，越错越深 |
| **任务特异 / 任务无关** | task-specific / task-agnostic | 只属于这局的 / 所有局共享的 |
| **消融实验** | ablation | 只去掉一个部件、其他全不变，看性能变化 |
| **配对差** | paired difference | 同一局同一随机种子下"方法 A 减方法 B"，消掉局的难度差异 |
| **标准误 (SE)** | standard error | 均值本身的波动范围。差值是 SE 的 2 倍以上才通常算显著 |
| **蒸馏** | distillation | 让学生模型去模仿老师模型的输出 |
| **软目标 / 硬标签** | soft target / hard label | 软 = 概率分布 `[0.1,0.8,0.1]`；硬 = one-hot `[0,1,0]` |
| **暗知识** | dark knowledge | 软目标里"类与类相对相似性"的信息 |
| **停止梯度** | detach / stop-gradient | 把老师的输出当常数，梯度只走学生 |
| **原型** | prototype | 某一类所有样本特征的**平均值**（这类的"重心"） |
| **标签传播** | label propagation | 让标签沿着"相似度"扩散（像水沿管道流） |
| **硬钳制** | clamping | 每轮迭代后把有标签点的值强行改回真实标签 |
| **低密度分离** | low-density separation | 假设决策边界应从数据稀疏的空白地带穿过 |
| **流形** | manifold | 高维数据实际分布在一个低维曲面上 |
| **直推 / 归纳** | transductive / inductive | 直推 = 预测时能看到测试样本的输入；归纳 = 看不到 |

# 第一章 · 三种半监督方法详解 ⭐必讲

## 1.0 先建立统一视角：三者其实是同一个模板

### 【结论】

三种方法在数学上都可以写成**同一个形式**：

$$\mathcal L = \underbrace{\mathcal L_{\text{sup}}}_{\text{有标签数据的损失}} \;+\; \lambda\cdot\underbrace{\mathcal L_{\text{unsup}}}_{\text{用无标签数据构造的"额外监督"}}$$

**差别只在 $\mathcal L_{\text{unsup}}$ 怎么定义。**

### 【对比表】

| 方法 | $\mathcal L_{\text{unsup}}$ 是什么 | 需要增广吗 | 需要置信阈值吗 |
|---|---|---|---|
| **Pseudo-Label** | 让模型去拟合**自己给出的硬标签**（argmax） | 不需要 | 不需要 |
| **VAT** | 让模型在**自己最敏感的方向上**输出不变 | 不需要 | 不需要 |
| **FixMatch** | 让模型在**强增广视图**上复现**弱增广视图的硬标签** | **需要** | **需要** |

### 【白话总纲】

三者都是"**让模型自己给自己出题**"。区别在于出题的方式：

* **PL** 是"我说什么就是什么"——自己预测，自己当答案；
* **VAT** 是"哪里最容易变我就偏要你不变"——专挑最敏感方向加干扰；
* **FixMatch** 是"给你看两张变形程度不同的图，你要说同一个答案"。

### 【为什么这个视角重要】

因为**换半监督方法，本质上只是换"老师怎么造、目标软还是硬、要不要过滤"这几个开关**。所以工程上可以把它们做成**可插拔的组件**（→ 第七章）。

## 1.1 Pseudo-Label（Lee, ICML 2013 Workshop）

### 【一句话原理】

用当前模型对无标签样本预测出的**最大概率类别**当作它的"伪标签"，然后把这些无标签样本当有标签数据一起训练。

### 【流程】

1. 用有标签数据（$D_l$，$n$ 个 mini-batch）正常训练模型；
2. 拿模型对无标签数据（$D_{ul}$，$n'$ 个 mini-batch）做前向，取概率最大的类：
   $$y'_i=\mathbb 1\big[i=\arg\max_{i'} f_{i'}(x)\big]$$
3. 把 $(x,\,y')$ 当有标签样本加入损失；**每更新一次权重就重新算一次伪标签**；
4. 无标签项权重 $\alpha(t)$ 用 **ramp-up** 从 0 慢慢升到 $\alpha_f$：
   $$\alpha(t)=\begin{cases}0,& t<T_1\\ \dfrac{t-T_1}{T_2-T_1}\alpha_f,& T_1\le t<T_2\\ \alpha_f,& t\ge T_2\end{cases}$$
   论文默认 $\alpha_f=3$，$T_1=100,\ T_2=600$（$t$ 单位是 epoch）。

### 【总损失】

$$\mathcal L=\frac1n\sum_m\sum_i L(y_i^m,f_i^m)\;+\;\alpha(t)\cdot\frac1{n'}\sum_m\sum_i L(y'^m_i,f'^m_i)$$

### 【关键术语】

* **伪标签 (pseudo-label)**：模型自己的预测被当作"真标签"使用。
* **ramp-up / 确定性退火 (deterministic annealing)**：一开始不完全相信伪标签，随训练逐渐加大它的权重。
  论文原话：*"If α(t) is too high, it disturbs training even for labeled data. Whereas if α(t) is too small, we cannot use benefit from unlabeled data."*
  以及：*"the deterministic annealing process, by which α(t) is slowly increased, is expected to help the optimization process to avoid poor local minima"*
* **熵最小化 (entropy minimization)**：论文证明了**硬伪标签 + 交叉熵 ≈ 熵最小化**——把预测分布推向 one-hot，就等价于让预测的熵变小。
  论文原文：*"Our method encourages the predicted class probabilities to be near 1-of-K code via training with unlabeled data and Pseudo-Labels, so the entropy of (17) is minimized. Thus **our method is equivalent to Entropy Regularization**."*

### 【白话理解】

> 一个学生先跟老师学几道题，然后开始自己做练习题，**把自己做出的答案当作标准答案继续练**。练得越久就越相信自己的答案（$\alpha(t)$ 上升）。

### 【论文中的实验证据】

Table 1（MNIST 网络输出的条件熵，越低越"确定"）：

| | train | unlabeled | test |
|---|---|---|---|
| dropNN（无伪标签） | 2.63×10⁻⁹ | 0.0349 | 0.0317 |
| +PL（加伪标签） | 6.10×10⁻⁹ | **0.0067** | **0.0114** |

论文原文：*"the entropy of unlabeled data get lower by Pseudo-Label training, in addition, the entropy of test data get lower along with that. This makes the classification problem easier even for test data and makes the density of data points lower at the decision boundary. According to cluster assumption, we can get the better generalization performance."*

Table 2（MNIST 测试错误率 %，标签数 100/600/1000/3000）：

| 方法 | 100 | 600 | 1000 | 3000 |
|---|---|---|---|---|
| dropNN（无伪标签） | 21.89 | 8.57 | 6.59 | 3.72 |
| **+PL** | **16.15** | **5.03** | **4.30** | **2.80** |
| +PL+DAE | 10.49 | 4.01 | 3.46 | 2.69 |

**增益：−5.74 / −3.54 / −2.29 / −0.92** —— **标签越少，增益越大**。

### 【适用条件与失效条件】

* **成立前提（论文隐含）**：基模型的 argmax 大体正确。论文最弱的一个设置是 MNIST 10 类、100 个标签、错误率 21.89%（≈78% 准确，随机是 10%）。
* **无标签量要远大于有标签量**：论文用 60,000 个无标签样本（与有标签比 100:1 ~ 600:1）。
* **论文数据每类样本数相同**（"The training set has the same number of samples on each label."）。
* **失效模式**：**没有任何置信度过滤**，错误的伪标签会被反复注入，形成 **confirmation bias（确认偏误）**。这是它最大的弱点。
* **论文完全没讨论**：confirmation bias、类别不平衡、校准。
* **我们在真实水数据上的实测**：把"自己给自己打标签"直接用在**回归**上会**梯度恒等于 0**（因为目标就等于预测值）。必须改成**滞后的 EMA 教师**（即 Mean Teacher 的做法），才有效。**这是本阶段最重要的工程发现之一。**

## 1.2 VAT（Miyato et al., TPAMI 2019）

### 【一句话原理】

在每个样本附近，找一个**最能改变模型输出分布的方向**（"虚拟对抗方向"），然后要求模型在这个方向上输出**保持不变**。

### 【流程】

1. 对每个输入 $x$，采一个随机单位方向 $d$；
2. 在 $x+\xi d$ 处计算输出分布与 $x$ 处输出分布的 KL 散度，对它求关于扰动 $r$ 的梯度 $g$（$\xi=10^{-6}$）；
3. 把 $g$ 归一化再乘上半径 $\epsilon$，得到虚拟对抗扰动：
   $$r_{\text{vadv}}=\epsilon\cdot\frac{g}{\|g\|_2}$$
4. 最小化"原始输入"与"被扰动输入"的输出分布之间的 KL：
   $$\mathcal L_{\text{LDS}}=D_{KL}\big[p(y|x,\hat\theta)\,\big\|\,p(y|x+r_{\text{vadv}},\theta)\big]$$
5. 总损失：$\mathcal L(D_l,\theta)+\alpha\cdot R_{\text{vadv}}$，其中
   $$R_{\text{vadv}}=\frac1{N_l+N_{ul}}\sum_{x^*\in D_l\cup D_{ul}} \mathcal L_{\text{LDS}}(x^*,\theta)$$
   默认 $\alpha=1$、$K=1$ 次幂迭代。

### 【为什么不能像 FGSM 那样一阶近似（这是 VAT 的技术核心）】

普通对抗训练（FGSM）用 $\nabla_x$ 的一阶近似。但这里 $D$ 在 $r=0$ 处的**梯度恒为 0**（因为 $x$ 与 $x+0$ 的分布相同），一阶近似退化。

**论文原文**：
> "the evaluation of $r_{\text{vadv}}$ cannot be performed with the linear approximation as in the original adversarial training (Eq.(3)) because **the gradient of $D[p(y|x^*,\hat\theta),p(y|x^*+r,\hat\theta)]$ with respect to $r$ is always 0 at $r=0$**."

所以必须用**二阶信息**——$D$ 关于 $r$ 的 Hessian 主特征向量就是最敏感方向：

$$D(r)\approx\tfrac12 r^\top H r,\qquad r_{\text{vadv}}\approx\epsilon\cdot u_1(H)$$

**工程上为了避开二阶导，用幂迭代 + 有限差分近似**：

$$Hd\approx\frac{\nabla_r D\big|_{r=\xi d}-\nabla_r D\big|_{r=0}}{\xi}=\frac{\nabla_r D\big|_{r=\xi d}}{\xi}$$

论文发现 $K=1$ 次就够：
> "Surprisingly, only one power iteration was sufficient for high performance on various benchmark datasets."

### 【关键术语】

* **局部分布平滑性 (LDS, Local Distributional Smoothness)**：模型输出分布在每个样本附近有多"不平滑"，VAT 就是把它当正则项压小。
  论文原文：*"The loss LDS(x,θ) can be considered as a negative measure of the local smoothness of the current model at each input data point x, and its reduction would make the model smooth at each data point."*
* **虚拟对抗方向 (virtual adversarial direction)**：注意是"虚拟"——它**不需要真实标签**，用的是模型自己的分布。
  这是 VAT 能做半监督的原因，论文原文：*"as opposed to adversarial training, the definition of virtual adversarial perturbation **only requires input x and does not require label y**. This is the property that allows us to apply VAT to semi-supervised learning."*
* **KL 散度**：衡量两个概率分布差异的量。

### 【白话理解】

> 一般人加噪声是"随便找个方向晃一晃"。VAT 是"**先用几分钟找出模型最怕被晃的那个方向，然后专门朝那个方向晃，逼模型在这个方向上站稳**"。

论文自述的方法定位：
> "Our proposed regularization technique is a method that trains the output distribution to be isotropically smooth around each input data point **by selectively smoothing the model in its most anisotropic direction**."

（沿**最各向异性的方向**有选择地平滑——这是它的卖点。）

### 【论文中的实验证据】

Table 4（SVHN / CIFAR-10 半监督，无图像增广）：

| 方法 | SVHN (N_l=1000) | CIFAR-10 (N_l=4000) |
|---|---|---|
| Π model | 5.43 (±0.25) | 16.55 (±0.29) |
| RPT | 8.41 (±0.24) | 18.56 (±0.29) |
| VAT | 5.77 (±0.32) | 14.18 (±0.38) |
| **VAT+EntMin** | **4.28 (±0.10)** | **13.15 (±0.21)** |

Table 1（MNIST 有监督，60,000 标注，测试错误率 %）：

| 方法 | 错误率 |
|---|---|
| Baseline (MLE) | 1.11 (±0.06) |
| RPT | 0.84 (±0.03) |
| Adversarial, L2 | 0.71 (±0.03) |
| **VAT** | **0.64 (±0.05)** |

**超参数**：MNIST 有监督 $\epsilon=2.0$；半监督搜索范围 [0.05, 10]；SVHN≈3.0、CIFAR-10≈8.0。$\alpha=1$、$K=1$、$\xi=10^{-6}$、KL 散度、Adam。

### 【重要提醒：$\epsilon$ 必须按维度换算】

论文的 $\epsilon$ 是**整条输入向量的 L2 半径**。用论文配置反推逐坐标扰动幅度（$\epsilon/\sqrt I$）：

| 数据集 | 维度 $I$ | 论文 $\epsilon$ | 逐坐标 RMS |
|---|---|---|---|
| MNIST | 784 | 2.0 | **0.071** |
| SVHN | 3072 | 3.0 | **0.054** |
| CIFAR-10（白化后） | 3072 | 8.0 | **0.144** |

**所以论文里"最优 $\epsilon$"对应的逐坐标扰动都是 0.05–0.15 个坐标单位。** 对 $I=9$ 的 z-score 特征，合理范围是

$$\epsilon\approx0.05\sqrt9\sim0.15\sqrt9=[0.15,\ 0.45]$$

**绝不能照抄 2.0/3.0。** 若按 MNIST 的 2.0 用在 9 维上，意味着每个特征平均被推动 $2/3\approx0.67$ 个标准差——在表格数据里那已经是另一个数据点了。

论文还指出：小 $\epsilon$ 时正则强度 $\propto\alpha\epsilon^2$，因此**优先调 $\epsilon$ 而不是 $\alpha$**。

### 【优点与失效条件】

* **优点**：不需要标签、**不需要数据增广**、不需要置信度阈值——三者里对数据前提要求最少，理论上最优雅。
* **失效条件**：它要求"输入空间的邻域在语义上是有意义的"（图像上成立：小幅 L2 扰动后还是同一张图；**表格/普通数值特征上不成立**）。
* **⚠ 我们的理论发现（本阶段亮点）**：VAT 的"选最各向异性方向"这个卖点，**在输出维度不足时会退化**。详见**第六章**。

## 1.3 FixMatch（Sohn et al., NeurIPS 2020）

### 【一句话原理】

用**弱增广**图像的预测生成伪标签，用**置信度阈值**筛掉不可靠的，然后要求模型在**强增广**的同一样本上复现这个伪标签。

### 【流程】

1. **有标签数据**：对**弱增广** $\alpha(x)$ 做标准交叉熵：
   $$l_s=\frac1B\sum_b H\big(p_b,\;p_m(y|\alpha(x_b))\big)$$
2. **无标签数据**：
   * 弱增广视图做预测 $q_b=p_m(y|\alpha(u_b))$，取硬伪标签 $\hat q_b=\arg\max q_b$；
   * 用置信度 $\max(q_b)$ 与阈值 $\tau$ 比较，得到 0/1 掩码 $m_b=\mathbb 1(\max q_b\ge\tau)$；
   * 对**强增广**视图 $A(u_b)$ 的预测，与硬伪标签算交叉熵，只保留掩码为 1 的样本：
     $$l_u=\frac{1}{\mu B}\sum_{b=1}^{\mu B}\mathbb 1\big(\max(q_b)\ge\tau\big)\,H\big(\hat q_b,\;p_m(y|A(u_b))\big)$$
3. 总损失：$l_s+\lambda_u l_u$。

### 【默认超参（论文主实验）】

| 超参 | 值 |
|---|---|
| 置信阈值 $\tau$ | **0.95** |
| 无标签损失权重 $\lambda_u$ | **1** |
| 无标签:有标签 batch 比 $\mu$ | **7** |
| 有标签 batch $B$ | **64**（→ 每步 448 个无标签样本） |
| 初始学习率 | 0.03（SGD + Nesterov 0.9） |
| 训练总步数 $K$ | **2²⁰ ≈ 1,048,576** |
| 学习率调度 | 余弦 $\eta\cos(7\pi k/16K)$ |
| 优化器 | SGD + momentum（论文说 Adam 更差） |

### 【关键术语】

* **弱增广 / 强增广**：弱 = 水平翻转 + 小幅平移（几乎不改变语义）；强 = RandAugment / CTAugment + Cutout（大幅改变外观但仍是同一类物体）。
* **置信度阈值 $\tau$**：只采信"模型很有把握"的伪标签。
* **一致性正则 (consistency regularization)**：要求模型对同一语义的不同视图给出一致输出。

### 【白话理解】

> 给模型看一张正常的图，如果它很确定这是"狗"，就把"狗"这张标签贴上去；然后把同一张图做大幅变形（旋转、变色、遮挡），**要求模型在变形图上仍然说"狗"**。**门槛在于"很确定"**——不确定的样本直接丢掉。

### 【为什么有效（论文的直觉）】

**① 硬标签 + 阈值 ≈ 熵最小化。**
论文原文：
> "The use of a hard label makes pseudo-labeling **closely related to entropy minimization**, where the model's predictions are encouraged to be low-entropy (i.e., high-confidence) on unlabeled data"

**② 阈值自带"课程"。**
论文原文（§2.2）：
> "This suggests that pseudo-labeling may produce a **natural curriculum 'for free'**."

**【白话】** 训练早期模型很菜，最大概率只有比如 0.6，**低于阈值 0.95** → 这些样本**全部被丢弃** → 无标签损失 = 0；训练后期模型变强了才放开。

**这就是"课程"的意思**（先易后难的学习节奏）。论文说这是"免费"得到的——不用自己设计课程表。**这也是它不需要对 $\lambda_u$ 做退火的原因。**

**③ 强增广的作用。**
论文消融显示：「用弱增广代替强增广」→ 精度峰值只到 **45%**，然后崩到 **12%**。说明强增广是它的命脉。

### 【论文中的实验证据】

CIFAR-10 主表（错误率 %，5 折均值）：

| 方法 | 40 标签 | 250 标签 | 4000 标签 |
|---|---|---|---|

### 【适用条件与失效条件】

* **强增广必须是语义有意义的**。图像有；**标准化后的表格特征没有**。
* **阈值会掐断无标签梯度**：论文明确说早期 $\max(q_b)<\tau$。在只走了几步的模型上，掩码期望≈0。
* **回归（连续目标）不适用**：没有 argmax、没有"最大概率"，阈值无从定义。
* **计算成本**：单次训练 ≈ 1.05×10⁶ 步 × (448 弱前向 + 448 强前向+反向)，无标签样本消耗约 **4.7×10⁸**。

# 第二章 · 问题的来源与研究假设 ⭐必讲

## 2.1 这个想法从哪来：MAML 论文自己留了一个口子

### 【要证明什么】

先确认"把半监督放进内层"在**框架层面是否合法**。如果合法、而论文又没试过，那才值得做。

### 【逻辑】

MAML 的算法骨架非常朴素：

```
第 5 行：从这个任务抽 K 个有标签样本，叫支持集 D
第 6 行：用 D 算一下当前参数的梯度        ← "损失函数"在这里插进去
第 7 行：沿着梯度走一步，得到 θ'（这一步叫"适应"）
第 8 行：再从同一个任务抽另一批有标签样本 D'，用 θ' 算损失
第 10 行：把这个损失对最初的 θ 求导，更新 θ（这一步叫"元更新"）
```

**关键就在第 6 行那个"损失函数"**。

### 【依据 · 论文原文（MAML, ICML 2017）】

> "We make no assumption on the form of the model, other than to assume that it is parametrized by some parameter vector θ, and that **the loss function is smooth enough in θ** that we can use gradient-based learning techniques."

> Algorithm 2 第 6 行："Evaluate $\nabla_\theta L_{T_i}(f_\theta)$ using $D$ and **$L_{T_i}$ in Equation (2) or (3)**"

—— 式(2) 是回归用的 MSE，式(3) 是分类用的交叉熵。**这句话把损失函数当成一个可替换的插件。**

> "The step size α may be fixed as a hyperparameter or meta-learned."

> "since our method merely produces a weight initialization, **adaptation can be performed with any amount of data and any number of gradient steps**"

> §5.2：FOMAML 是 "a first-order approximation of MAML, where these second derivatives are omitted"

### 【白话】

论文写的是"用式(2)或式(3)"，那自然就会想：**我能不能在这个位置再加一项？**

$$\theta'=\theta-\alpha\nabla_\theta\underbrace{\big[L_S(\theta;D)+\lambda L_U(\theta;D_U)\big]}_{\text{原来的 }L_S\text{ + 我加的半监督项}}$$

* $L_S$ = 支持集上的监督损失（原来的）
* $L_U$ = 无标签数据上的损失（我加的）
* $\lambda$ = 这一项占多大权重

而且论文还明确说"损失只要对 θ 光滑就行"、"适应阶段可以用任意多数据、任意多步"——**听起来完全是允许的**。

**顺带一提**：VAT 论文自己就承认"忽略一部分依赖"是可以接受的近似——
> "Our VAT therefore **ignores the dependency of $r_{vadv}$ on θ**."

这进一步给人信心"内层可插"。

### 【关键事实】

**MAML 全文没有出现 "unlabeled"、"semi-supervised" 这两个词。** 论文从没做过"内层加额外损失项"的实验。

### 【小结】

$$\boxed{\text{内层损失是"插件接口"} \;\wedge\; \text{论文从未试过半监督} \;\Longrightarrow\; \text{真实的研究空白}}$$

**翻译成人话**：论文留了个口子，但自己没往里塞过东西，所以值得试。

---

## 2.2 把想法变成可否证的假设

### 【要证明什么】

不能只说"我想试试"。要写成**能被实验打脸**的形式，否则最后只能得到"不行"这种很弱、很容易被质疑的结论。

### 【假设】

$$\textbf{H}_0:\quad \theta'=\theta-\alpha\nabla_\theta\big[L_S+\lambda L_U\big]\ \text{ 比 }\ \theta'=\theta-\alpha\nabla_\theta L_S\ \text{ 更好}$$

**H₀（零假设）就是一句大白话**：*"在内层加上半监督项，效果会更好。"*

### 【从 H₀ 推出两个可观测的预言】

| 预言 | 如果 H₀ 成立，应该观察到什么 | 为什么这算"预言" |
|---|---|---|
| **预言 A** | **至少某一种**半监督项应带来正增益 | 半监督方法有很多种，如果"内层这个位置对"，总该有一种能 work |
| **预言 B** | 因为任务特异部分随 $\alpha m$ 增大，**调强信号应该先变好、后变差**（倒 U 形） | 像调音量：太小听不见，太大破音，中间最好 |

### 【白话】预言 B 在说什么

* $\alpha$ = 每次走多远，$m$ = 走几步，**$\alpha m$ 大致就是"参数总共移动了多远的距离"**
* **移动距离小** → 模型还是原来那个通用模型，伪标签没变化 → 半监督项几乎不起作用（应该是"没效果"）
* **移动距离适中** → 模型开始带上"这一局"的特色，伪标签开始变得任务相关 → 应该**开始有用**（"变好"）
* **移动距离很大** → 模型已经彻底变成这一局的专用模型，甚至过拟合 → 可能又开始捣乱（"变差"）

**所以如果 H₀ 成立，曲线应该是个"倒 U 形"：先升后降。**

**这两条就是后面用来否证 H₀ 的武器。** 只要有一条不成立，H₀ 就被否证；两条都不成立，结论就很硬。

---

## 2.3 三个可选的注入位置

记内层步长 $\alpha$、步数 $m$、支持集 $D_S$、无标签池 $D_U$、查询集 $D_Q$。

| 位置 | 公式 | 含义 |
|---|---|---|
| **① 内循环（inner loop）** | $\theta'_i=\theta-\alpha\nabla_\theta\big[L_S+\lambda L_U\big]$ | 让半监督信号参与"任务适应"本身 |
| **② 外循环（meta-objective）** | $\theta\leftarrow\theta-\beta\nabla_\theta\sum_i\big[L_{T_i}(f_{\theta'_i})+\lambda' L_U(f_{\theta'_i})\big]$ | 半监督信号只塑造初始化 |
| **③ 适应之后（post-adaptation）** | $\theta_s=\mathrm{Adapt}(\theta_0,K)$，再用 $U$ 做一次独立的精炼 | 半监督与元学习**解耦**，分成两段 |

**【白话】** 这就是"把这个东西放在流程的哪一步"：
* **①** 放在**学这一局**的过程中；
* **②** 放在**塑造通用起点**的过程中；
* **③** 放在**学完这一局之后**。

**我们的实验把三个位置都测了。**

# 第三章 · 实验设计与结果 ⭐必讲

## 3.1 实验为什么必须这样设计（理解全部实验的钥匙）

### 【要证明什么】

普通的"簇状高斯"任务**根本回答不了我们的问题**，必须改造任务，让"表示学得好不好"成为决定成败的变量。

### 【白话】如果任务太简单，会发生什么

假设样本就是 `[x1, x2]` 两个数，5 个类各聚成一团：

* 查询集的点**自己就聚成 5 团**（因为每一类是一个高斯团）；
* 每个支持点**必然落在其中一团里**；
* 于是"把每一团贴上对应支持点的标签"就完事了 —— **这就是标签传播，它根本不需要神经网络学什么表示**。

**后果**：无论你把半监督项放在内层还是外层，**结果都好**，实验没有区分度，也说明不了任何问题。这种情况下的结论会退化成一句废话："**SSL 都能用**"。

**所以必须改造任务，让"表示学得好不好"变成决定成败的关键变量。** 我们加了两条设计。

---

### 【设计 1】加 6 个噪声维度

#### 具体怎么改

**改之前**：每个样本是 2 个数 → `[x1, x2]`
**改之后**：每个样本是 8 个数 → `[x1, x2, n3, n4, n5, n6, n7, n8]`

* **前 2 维 $(x_1,x_2)$**：承载**类别结构**，也就是真正有用的"信号"
* **后 6 维 $(n_3 \dots n_8)$**：纯噪声，从标准正态分布 $N(0,1)$ 随机抽出来，**和这个样本属于哪一类完全无关**

#### 关键在"尺度对比"

| | 大小 |
|---|---|
| **信号**：类中心分布在**半径 1** 的圆上，同类样本围绕中心波动，标准差 **σ = 0.35** | 有用信息幅度约 0.35 |
| **噪声**：6 个维度，每个从 $N(0,1)$ 抽，标准差 **1.0** | 噪声幅度约 1.0 |

那么两个样本之间的欧氏距离（也就是"它们有多像"），**绝大部分来自那 6 个噪声维度**，真正决定类别的 2 个维度只贡献一点点。

#### 【白话·比喻】

> 你想判断两个人的相似度，本来只需要看身高体重（2 个有用指标），但我又给你加了 **6 个完全随机的骰子点数**（今天掷出多少完全随机，和这两个人是谁无关）。你算"距离"的时候，**骰子点数的差异会把身高体重的差异彻底淹没**。你量到的基本上都是骰子。

#### 后果

**如果你直接在原始 8 维输入上算距离做标签传播，你量到的基本上都是噪声，传播就是瞎猜。**

实测结果印证了这一点：**31.33%**（5 分类完全随机是 20%）。

> 为什么不是正好 20%？因为那 2 个信号维度还在，多少提供了一点信息；但 31% 距离"能用"差得很远。

#### 这就逼出了元学习的价值

只有当模型学会 **"把 8 维压缩成 2 维、把 6 个噪声维度扔掉"**，标签传播才有意义。

**于是"表示学得好不好"就成了区分不同方法的关键变量**——这正是我们要研究的。

#### 四行数据证明这一点（同一批任务上的四种做法）

| 做法 | 标签传播准确率 | 白话 |
|---|---|---|
| 不用网络，直接在原始 8 维上传导 | **31.33%** | 被噪声淹没，接近瞎猜 |
| 用**随机初始化**网络提的特征传播 | **31.06%** | 网络没训练，提的特征也是乱的 |
| 用**普通预训练**（联合训练）网络的特征 | **25.23%** | 居然更差——它学的是"平均意义上好"，不是"容易区分" |
| 用 **MAML 元训练**网络的特征 | **82.64%** | **只有它学会了扔掉噪声** |

**前三行都在 25%~31% 徘徊（等于没用），只有第四行跳到 82.64%。**

**这直接证明了：在这个任务上，表示必须靠元学习获得，SSL 只有在好表示之上才有意义。**

---

### 【设计 2】任务特异性（相位随机 + 各向异性变换）

**目的：让模型不能"死记硬背"，必须"每局现推"。**

#### （a）类均值圆环

**【白话】** 5 个类中心不是随便撒的，而是**均匀分布在一个圆上**。比如半径 1 的圆，5 个中心的角度分别是 0°、72°、144°、216°、288°：

```
             类0 (0°)
               ●
      类4 ●         ● 类1
              ✕ 圆心
        ●           ●
      类3            类2
```

**为什么要摆成圆环？** 因为这样 5 个类**两两距离都一样**，不存在"某两类天生更容易混"的问题，任务难度是均衡的。

#### （b）相位（phase）随机

**【白话】** 如果每一局里这 5 个类中心**都在同一套位置**，那模型只要记住"角度 0 附近的就是类 0"就行了——**所有局都一样，元学习就没意义了**（等于只有一局）。

所以每一局把整个转盘**随机旋转一个角度** $\psi$：

* **任务 A**：类 0 在 10°，类 1 在 82°，类 2 在 154°……
* **任务 B**：类 0 在 143°，类 1 在 215°，类 2 在 287°……
* **任务 C**：类 0 在 271°，……

**这就是"任务特异性"**：每一局的规则都不一样。

**比喻**：每一局都是"**转了不同角度的同一个转盘**"。模型不能记住"黄色在哪个方向"，**必须从这一局给的 5 个支持点里，现推"这个转盘转了多少度"**。

这正是小样本学习的本质：**不是记住答案，而是从极少的例子里快速推断出当前任务的规则。**

#### （c）各向异性线性变换（anisotropic linear map）

**【白话】"各向异性"是什么意思？**

* **各向同性（isotropic）**：各个方向一视同仁，比如圆。
* **各向异性（anisotropic）**：**不同方向被拉伸的倍数不一样**，比如椭圆、平行四边形。

**【白话】我们具体怎么做？**

在旋转之外，再对坐标乘一个 2×2 矩阵 $A$，它的两个"拉伸倍数"（奇异值）取 $e^{\pm 0.4}$，大约是 **0.67 和 1.49**。

**举个直观的例子**：如果 $A=\begin{bmatrix}2&0\\0&0.5\end{bmatrix}$，那么

* 点 $(1,0)$ → $(2,0)$：**横着拉长 2 倍**
* 点 $(0,1)$ → $(0,0.5)$：**竖着压扁一半**

原来的圆形分布就被拉成了一个扁的椭圆。

**【白话】为什么要这么做？两个作用：**

**作用一：让"谁和谁近"变得不那么直观。**
拉长方向上距离被放大，压扁方向上距离被缩小。所以**看起来很近的两个点，可能其实属于不同类；看起来很远的两点，可能属于同一类**。单纯的"最近邻"会出错，模型必须学一个更聪明的度量。

**作用二：每局的拉伸方向不同 → 必须靠支持集推断。**
因为每局的 $A$ 都不一样（旋转 + 拉伸都是随机的），模型**不能死记**，只能从支持集里现推。

#### 【白话】为什么"任务特异性"这么重要

**如果所有局都是同样的转盘、同样的拉伸** → 模型可以学到一个固定的解 → **元学习退化成普通监督学习**，整个实验就没意义了。

**加上任务特异性之后** → 模型必须学会"**从少量支持点快速推断当前任务的规则**"——这正是 MAML 被设计出来解决的问题，也是我们要研究的那个能力。

### 【设计小结】

$$\boxed{\text{设计 1（噪声维度）保证"必须学表示"，设计 2（任务特异性）保证"必须靠支持集现推"}}$$

**两者合起来，才让"SSL 放在内层还是外层"这件事变成一个"有区分度"的实验。**

## 3.2 实验配置

5-way **1-shot**（每类只给 1 个标签，所以支持集共 5 个点）、查询集 75 点、元训练 2500 次迭代 × 每批 16 个任务、元测试 **400 个任务**；网络 8→40→40→5（ReLU）；MAML $\alpha=0.4$、训练 1 步内循环、评测 3 步；二阶用有限差分 HVP。

## 3.4 三个内循环项的设计动机 🔸答疑备用

**【如果被问"你为什么不直接试 FixMatch，非要自己设计这三个？"】**

### 【核心回答】

**因为不能只试一个方法。**

如果我只把 FixMatch 塞进 MAML 内层、发现掉点，会立刻遭到五个质疑：

1. "是不是 FixMatch 这个方法本身就不行？"
2. "是不是你的强增广做得太糙？"
3. "是不是阈值 τ 设错了？"
4. "是不是表格数据不适合 FixMatch，换个 SSL 方法就好了？"
5. "是不是你没调好？"

**要挡住这五个质疑，就必须从"方法层"下沉到"机制层"**：把三个方法**拆成零件**，把可能出问题的零件**一个个拿掉**，让内层 SSL 处在**最有利的环境**下。

### 【三个方法的零件拆解】

| 零件 | 作用 |
|---|---|
| **① 老师** | 谁产生"参考答案" |
| **② 目标形式** | 硬标签 / 软标签 / 不需要答案 |
| **③ 筛选开关** | 要不要按置信度筛掉一部分 |
| **④ 输入变换** | 要不要做增广或扰动 |

| | ① 老师 | ② 目标 | ③ 阈值 | ④ 输入变换 |
|---|---|---|---|---|
| **PL**（Lee 2013） | 当前模型 | 硬 argmax | ❌ 无 | ❌ 无 |
| **VAT**（Miyato 2019） | 自己（在扰动点上） | 不需要答案，用分布 | ❌ 无 | ✅ **对抗扰动** |
| **FixMatch**（Sohn 2020） | 自己（**弱增广**视图） | 硬 argmax | ✅ **τ=0.95** | ✅ **强增广** |

**FixMatch = PL + 阈值 + 强增广**（多了两个零件）。

### 【我们发现：零件③④ 在我们的数据上是"坏的"】

**零件③ 阈值：会掐断梯度。**
FixMatch 原文：*"pseudo-labeling may produce a **natural curriculum 'for free'**"* —— 训练早期 $\max(q_b)$ **小于** $\tau=0.95$，样本全被丢掉，无监督损失 = 0。
**在一个只走了 3–5 步的内层模型上，它根本不可能有那么自信**，所以掩码≈全 0，这一项等于没加。
**实测**：把 $\tau$ 从 0.95 降到 0.80，验证集 AUC 才从 0.61–0.63 恢复到 0.64–0.65。

**零件④ 强增广：表格数据没有语义增广。**
强增广（RandAugment、Cutout）是为图像设计的——旋转、变色、遮挡之后图还是同一个物体。**9 个标准化后的水质指标没有这种东西**：给 `z_ph` 加高斯噪声，得到的不是"同一物体的另一个视角"，只是一个**无意义的数值组合**。

### 【我的三个设计 = "把坏零件全拆掉，只留内核"】

| 我的设计 | ① 老师 | ② 目标 | ③ 阈值 | ④ 增广 |
|---|---|---|---|---|
| **熵最小化** | **没有老师** | —（只要求自信） | ❌ | ❌ |
| **原型蒸馏** | **支持集算出的类原型** | 软标签 | ❌ | ❌ |
| **LP 蒸馏** | **标签传播** | 软标签 | ❌ | ❌ |
| **冻结教师一致性** | **元初始化 $\theta_0$** | 软标签 | ❌ | ❌ |

**和三个原版方法的对应关系**：

| 我的设计 | 提取自谁 | 提取的是什么机制 |
|---|---|---|
| **熵最小化** | **PL 和 FixMatch 的共同内核** | 两者都是硬标签 → 都把预测推向 one-hot。**PL 原文**："our method is **equivalent to Entropy Regularization**"；**FixMatch 原文**："The use of a hard label makes pseudo-labeling **closely related to entropy minimization**" |
| **原型蒸馏** | FixMatch 的"**软标签 + 任务特异老师**"版本 | 用支持集造老师（Ren et al. 2018 的 soft k-means 思路），但把硬标签换软、把阈值去掉 |
| **LP 蒸馏** | 图方法（TPN / LaplacianShot 的思路） | 换一个**更强的、非参数的老师** |
| **冻结教师一致性** | **VAT 的家族**（一致性/平滑） | VAT 要的是"别在小扰动下改主意"；冻结教师要的是"别离起点太远"——都是"稳定性约束" |

### 【关键点：这是"最有利条件"】

> **给内层 SSL 创造一个"最理想的环境"——能去的障碍全去掉，能给的帮助全给上。**

具体说：
* ❌ 没有 argmax 的零梯度问题 → 因为用**软标签**（熵最小化则完全可微）
* ❌ 没有"表格没有语义增广"的问题 → 因为**不用增广**
* ❌ 没有"早期掩码全 0"的问题 → 因为**不用阈值**
* ❌ 没有"老师任务无关"的问题 → 因为**老师由支持集参数化**（原型、LP）

**如果在这么有利的条件下还是不行，那结论就不是"某个方法不好"，而是"这个位置不行"。**

### 【阶梯设计：无老师 → 弱老师 → 强老师】

```
熵最小化              原型蒸馏                    LP 蒸馏
（无老师）      →     （弱老师）        →        （强老师）
"你要自信"           "跟类中心走"                "跟邻居走"
完全任务无关         任务特异                    任务特异 + 结构信息
     ↓                    ↓                          ↓
 −12.81               −4.22                      −9.90
 （掉点）             （掉点）                    （掉点）
```

**"老师太弱"这个解释被排除了**——升级老师不但没救回来，强老师还掉得更狠。

### 【小白话·试药比喻】

> 你想知道"为什么这个药对这个病没用"。
> * **笨办法**：换个牌子的药再试一次 → 还是没用 → 你还是不知道为什么。
> * **聪明办法**：**把药拆成成分，一种一种单独试** → 发现每种成分单独用都没用 → 才敢说"不是成分的问题，是这个病根本不该吃这类药"。

### 【两层实验设计】

```
┌─────────────────── 第一层：机制层（拆零件）──────────────────┐
│  熵最小化 / 原型蒸馏 / LP 蒸馏 / 冻结教师一致性                 │
│  特点：把阈值、增广这些"坏零件"全拆掉，制造最有利条件            │
│  结果：全部掉点（−12.81 / −4.22 / −9.90）                     │
└────────────────────────────────────────────────────────────────┘
                              ↓ 结论一致
┌─────────────────── 第二层：方法层（直接跑原版）────────────────┐
│  Pseudo-Label / FixMatch（回归形式）/ VAT（回归形式）           │
│  特点：在真实水数据集上直接实现三个方法的回归版本               │
│  结果：FixMatch 与 VAT 的权重被源域调参选成 0（=别用）；        │
│        Pseudo-Label 放到"适应之后"才有效（−11.8%~−24.1%）      │
└────────────────────────────────────────────────────────────────┘
```

**两层实验、两种做法、结论一致 → 不是方法的问题，是 inner loop 这个位置的问题。**

## 3.5 结果二：预言 B 被否证

### 【要证明什么】

排除"内层 SSL 只是信号太弱"这个最自然的辩解。

### 【做法】

**固定同一个 MAML 主干**（$\alpha=0.4$、1 步训练），只在**评测时**改变内层的 $\alpha$ 和 $m$。支持集损失完全一样，唯一差别是内层有没有加无标签项。

**【白话】为什么要固定主干、只改评测参数**

因为想验证的变量是"**参数移动距离 $\alpha m$**"，不是"训练方式"。
* 如果每个 $\alpha$ 都重新训一个主干，差异里就混进了"训练方式不同"的干扰；
* 固定主干、只改评测参数，就**只改变了一件事**——这就是控制变量。

### 【数据】

内循环熵最小化带来的 ΔAUC（相对同行纯监督基线）：

| | m=1 | m=3 | m=8 |
|---|---|---|---|
| **α=0.05** | +0.83 | +0.40 | −0.68 |
| **α=0.1** | +0.19 | −0.09 | −4.35 |
| **α=0.2** | −0.09 | **−12.36** | **−16.69** |
| **α=0.4** | −0.17 | **−12.81** | **−23.33** |
| **α=0.8** | −0.28 | −7.28 | −17.68 |

**对照：同一张表里加"冻结初始化的教师"一致性项，m=1 时全部精确为 0.00.**

### 【怎么读】

* **列** = 内层走几步（$m$）
* **行** = 内层每步走多远（$\alpha$）
* **格子里的数** = "加熵最小化"相比"不加"好多少个百分点

**看左上角**：α=0.05、m=1，参数总共只移动了很少 → **+0.83**，基本等于没动（在噪声范围内）。
**看中间**：α=0.2、m=3 → **−12.36**，掉了一大截。
**看右下**：α=0.4、m=8 → **−23.33**，掉得最惨。

### 【形状说明了什么】

预期是**倒 U 形**：太小没效果 → 适中变好 → 太大变差。

**实际看到的是**：只有"死区"（左上角，影响 ≤1 个点）和"断崖"（越往右下掉得越狠）。**没有"变好"的中间区域。**

$$\boxed{\text{预言 B 被否证：没有"先升后降"，只有"死区 → 断崖"}}$$

### 【为什么这一步很重要】

它排除了一个很自然的辩解：**"是不是信号太弱，所以没效果？我把它调强不就好了？"**

实验结果说：**不是。调强之后不是变好，而是急剧变差。**

于是失败的真正原因不再是"力度不够"，而是"**方向错了**"——**它一使劲就往错误的方向推。**

**这句话把问题从"工程调参"推进到了"机理"，是整条推理链的转折点。**

### 【一个代码正确性的自检】

"**冻结教师一致性**"（意思是"别偏离起点太远，保持和初始参数 $\theta_0$ 一致"）在 m=1 那一列，效果**精确地等于 0.00**——不是"约等于"，是**严格的 0**。

**为什么？** 因为在 $\theta=\theta_0$ 这个点上，"和初始参数一致"这件事本来就完全满足，损失的梯度也恰好是 0。

**这个 0.00 的意义**：它是一个**代码正确性的自检**——如果实现有 bug，它不可能精确为 0。**这说明实验装置是可靠的，前面的负增益不是代码问题。**

# 第四章 · 机理分析：为什么内层这个位置天生不适合 ⭐必讲

四条机理，每条都配论文原文或实验证据。

---

## 4.1 机理 M1 · 时间尺度错配（成本层面）

### 【论文原文（FixMatch 主实验超参）】

> "λu = 1, η = 0.03, β = 0.9, **τ = 0.95, µ = 7, B = 64**, K = 2²⁰"

* K = 2²⁰ ≈ **1,048,576** 步（约 100 万步）
* B = 64（每步 64 个有标签样本）
* µ = 7 → 每步 **448 个无标签样本**

### 【数据：数量级对比】

| | 无标签样本消耗量 |
|---|---|
| FixMatch 单次运行 | $448 \times 1{,}048{,}576 \approx 4.7\times10^8$（**4.7 亿**） |
| MAML 内循环（5 步 × 每任务 160 个） | $\approx 800$（**800**） |
| **差距** | **约 6 个数量级（一百万倍）** |

### 【白话】

自训练、一致性正则这些方法的收益，来自"**反复练很久**"这个**过程**，而不是那个损失函数长什么样。

**比喻**：FixMatch 是"每天背 448 个单词、坚持 100 万天"；而 MAML 的内循环是"给你 800 个单词、背 5 遍"。

**把一个需要练 100 万步才见效的机制，塞进一个只走 5 步的算子里——它来不及起作用。**

**这不是"实现问题"，是"预算问题"。**

---

## 4.2 机理 M2 · argmax 与阈值构成"零梯度面"（信息层面）

### 【论文原文（FixMatch）】

> "we use $\hat q_b = \arg\max(q_b)$ as a pseudo-label"
> $m_b=\mathbb 1\big(\max(q_b)\ge\tau\big)$

### 【数学事实】

**$\arg\max$ 和 $\mathbb 1(\cdot\ge\tau)$ 都是"分片常数"函数**——输入不跨越某个边界时，输出完全不变。

### 【白话】什么叫"分片常数"、为什么导数为 0

想象一个**台阶**：

> 你站在第 3 级台阶上，往左挪一点、往右挪一点，**你还是站在第 3 级，高度没变**。只有当你挪得足够多、跨过边缘，才会突然跳到第 2 级或第 4 级。

* **"高度"** = argmax 的输出（类别编号）
* **"位置"** = 模型的参数
* **"没变"** = 导数为 0

**所以**：元梯度"看不到"该采信哪些样本、也"看不到"阈值该定多少——**因为这些都是台阶，不是斜坡。而梯度下降只能在斜坡上走。**

### 【更要命的是"课程效应"】

**FixMatch 论文原文（§2.2）**：
> "This suggests that pseudo-labeling may produce a **natural curriculum 'for free'**."

（模型置信度 $\max(q_b)$ 在训练早期通常小于阈值 $\tau$）

**白话**：
* **训练早期**：模型还很菜，预测的最大概率只有比如 0.6，**低于阈值 0.95** → 这些样本**全部被丢弃** → 无标签损失 = 0
* **训练后期**：模型变强了，最大概率能到 0.97 → **超过阈值** → 这些样本被采用

**所以阈值自动实现了"先易后难"的学习节奏**（这就是"课程"），论文说这是"免费"得到的。

### 【对 MAML 内循环意味着什么】

内循环只走 1–5 步，参数只移动了 $O(\alpha m)$ 那么一点点。在这个"只轻轻推了一下"的模型上：

$$\max(q_b)\ \text{远小于}\ 0.95 \;\Longrightarrow\; \text{掩码几乎是全 0} \;\Longrightarrow\; \textbf{无监督梯度是空的}$$

**就是说：FixMatch 的这一项在内层根本没生效，权重多大都一样。**

### 【实验印证】

我们在一份数据上实测：$\tau=0.95$ 时验证集 AUC 只有 0.61–0.63；把 $\tau$ **降到 0.80** 才回到 0.64–0.65。

**【白话】** 想让它起作用，就必须把阈值降到 0.8 左右。但那样做，**你就已经不是在用 FixMatch 的设计了**（论文的整套超参都是围绕 0.95 调的）。

---

## 4.3 机理 M3 · 任务特异性只有 $O(\alpha m)$（核心机理）

### 【推导】

$$\theta'=\theta_0-\alpha\nabla L_S(\theta_0)\quad\Longrightarrow\quad \theta'=\theta_0+O(\alpha m)$$

### 【白话】把这一步拆开讲

**第一步**：梯度下降一步是 $\theta'=\theta_0-\alpha\nabla L_S(\theta_0)$。
* $\alpha$ 是步长（MAML 常用 0.01–0.4）
* $\nabla L_S$ 是支持集上的梯度（支持集只有 K 个点，所以梯度不大）

**第二步**：两项都很小 → **$\theta'$ 离 $\theta_0$ 很近**。用数学符号写就是 $\theta'=\theta_0+O(\alpha m)$，"移动距离和 $\alpha m$ 成正比"。

**第三步（关键）**：**伪标签是由 $\theta'$ 算出来的**。
* 既然 $\theta'$ 几乎就等于 $\theta_0$，
* 那么"$\theta'$ 对无标签数据的预测" $\approx$ "$\theta_0$ 对无标签数据的预测"。

**第四步（最关键）**：**$\theta_0$ 是所有任务共用的！**
$\theta_0$ 是"跨任务共享的起点"——它在所有局里都是同一个。所以由它产生的伪标签，**几乎不包含"当前这一局"的任何特色**。

### 【白话·比喻】

> 你在教一个学生做**这一道题**（当前任务）。但你给的"参考答案"，是从**通用教科书**里抄的（共享起点 $\theta_0$），而不是针对这道题算出来的。

于是你加的这一项 $L_U$，**约束的主要是那本通用教科书（共享参数 $\theta_0$），而不是这道题的具体解法（任务特异的适应）**。

**换句话说：它退化成"在训练时加了一个正则项，防止起点跑太远"，而不是"每个任务各自的半监督适应"。**

### 【一个数学说明】

"任务特异性只有 $O(\alpha m)$"这句话的意思是：

**内层半监督项对参数的影响里，"所有任务都一样"的部分占了大头，而"属于当前任务"的部分只有 $\alpha m$ 那么小。**

$\alpha m$ 有多小？$\alpha$ 取 0.4、$m$ 取 3，$\alpha m=1.2$——听起来不小，但它是**相对整套参数的尺度**来说的，而且还要乘上梯度的大小，实际移动量很小（这就是为什么 3.5 节那张表里"死区"覆盖了很大一片）。

### 【这一点被实验直接证实——整条链最重要的证据】

如果 M3 是对的（"内层 SSL 实际上只是在正则化 $\theta_0$"），那么**把它放到外循环（元目标）里也应该有效**。实测：

| 位置 | 效果 |
|---|---|
| 内层（适应项） | 熵最小化 **−12.81** |
| **外层（元正则）** | 熵最小化 **+3.58**（75.86 → 79.44） |

**同一个方法、同一个数据、同一个 $\lambda$，换个位置就从 −12.81 变成 +3.58。**

$$\boxed{\text{这证明问题出在"位置"，而不是"方法"}}$$

---

## 4.4 机理 M4 · 退化解（目标层面）

### 【逻辑】

按 M3 的结论，把老师改成"**由支持集参数化**"的（原型、标签传播），任务特异性就会变强。**那会怎样？答案是：会塌缩。**

### 【白话】什么是"老师由支持集参数化"

M3 里说"伪标签来自共享起点，没有任务特色"。那自然的改进是：**让伪标签来自"支持集算出来的东西"，这样它就有任务特色了。**

两个例子：
* **原型（prototype）**：把每一类支持集样本的特征取平均，得到该类的"代表点"。然后"谁离这个代表点近就判给谁"。因为支持集是这一局特有的，所以这个老师**有任务特色**。
* **标签传播**：在图上让标签从有标签点扩散出去，也是用支持集算的，**也有任务特色**。

### 【数据：结果反而更糟】

| 做法 | 主干准确率变化 |
|---|---|
| 原型蒸馏进内层 | 75.86 → **54.34**（随机是 20%） |
| LP 蒸馏进内层 | 75.86 → **42.23** |

### 【白话】为什么会塌缩

因为这两个老师的"最优解"都是**没意义的退化解**：

* **原型蒸馏的最优解**：把所有无标签点都拉到它们各自的原型上 → 最终**所有同类点塌成一个点**，特征失去区分度。
* **熵最小化的最优解**：把所有点都推向同一类 → 预测全变成同一个答案。

**而外层只监督查询集的损失 $L_Q$，它和 $L_U$ 的最优解不一致。** 两个目标互相拉扯，内层 SSL 项又权重不小，于是表示被拉垮。

### 【论文原文支持（Ren et al., ICLR 2018）】

他们用类似的方法（soft k-means 精修原型），但是能行：

> "we chose to **extend Prototypical Networks** in this work for its simplicity and efficiency."

（我们选择扩展原型网络，因为它简单高效。）

—— 注意这句的言下之意：他们**选择了 prototype 网络这类 metric-based 方法，而没有选择 MAML 这类梯度型方法**。

> "We could perform several iterations of refinement... However... **found results to not improve beyond a single refinement step**."

（我们试过多次迭代精修……**发现超过一步就没有提升了**。）

### 【白话】为什么他们能行，我们不行

因为他们的精修是 metric-based 流水线里的**一步闭式解**：
* **闭式解** = 有现成公式直接算出来，不用迭代
* **不参与二阶求导** = 元梯度不用穿过它，不会和目标互相拉扯

**而我们做的是"把半监督项塞进梯度内循环"——它必须参与二阶求导，于是必然要和外层目标争夺梯度。**

### 【由此得出"内层 SSL 有效"的三个必要条件】

1. 是**闭式或一步**算子（不是需要上万步的动力学）；
2. 输出**由支持集显式参数化**（任务特异）；
3. 目标与元目标**方向一致**（不产生退化解）。

**而这三条在 MAML 式梯度内循环里很难同时满足**——我们的三个设计分别满足了 (2)，但都败在 (3)。

---

## 4.5 机理小结

$$\text{内层 SSL 失效} = \underbrace{\text{M1 预算不够}}_{\text{来不及生效}} + \underbrace{\text{M3 任务无关占主导}}_{\text{退化成对 }\theta_0\text{ 的正则}} + \underbrace{\text{M4 目标退化}}_{\text{一旦生效方向就错}} + \underbrace{\text{M2 阈值掐断}}_{\text{梯度为空}}$$

### 【白话版总结】

* **M1**：这个机制需要跑很久才见效，内层只跑 3–5 步，根本来不及。
* **M2**：FixMatch 的筛选开关（阈值）在这么短的适应里几乎全是关着的，所以那部分损失等于 0。
* **M3**：内层只轻轻动了一下参数，所以"无标签数据的预测"几乎就是"通用起点"的预测，没有任务特色 → 这项损失主要在管**共用的起点**，而不是**这一局的具体解法**。
* **M4**：如果想让它变得有任务特色（用原型、用标签传播），这些老师的"最优解"本身是塌缩的，会把模型带坏。

### 【对项目的意义】

**这直接回应了项目核心问题①的前半句**："在标注样本极少的条件下，如何引入无标签数据"——**答案是：不放进 inner loop**。

而且**误差传播问题被结构性消除**：如果半监督不在内层，它就**没有通向 meta-gradient 的二阶求导路径**。

# 第五章 · 正面验证与三段式 ⭐必讲（整条链最关键）

## 5.1 换个位置就有效

### 【逻辑】

如果结论只是"内层不行"，那只是一个**负面结果**，很容易被认为"是你没做好"。
**必须证明"换个位置就行"，才能把结论从"半监督没用"精确地收窄到"半监督的位置错了"。**

### 【数据】

| 主干 | 只做监督适应 | **适应后 + 标签传播** | 增益 |
|---|---|---|---|
| 随机初始化 | 31.19 | 31.06 | **−0.13** |
| 联合预训练 | 25.37 | 25.23 | **−0.14** |
| **MAML 二阶** | **75.86** | **82.64** | **+6.78** |
| FOMAML | 78.94 | 81.30 | +2.36 |

### 【白话】这张表同时说明两件事

**第一件**：适应之后做半监督确实有效（+6.78）。同样的任务、同样的标签预算，只是在"适应完之后"多用了一下无标签数据，准确率从 75.86 涨到 82.64。

**第二件（更重要）**：**第三段的增益 100% 来自第一段学到的表示。**
看前两行——**起点不好的时候（随机初始化、普通预训练），标签传播的增益是 0（甚至 −0.13）**。

**【白话】** 标签传播本身不"生产"信息，它只是把**已有的、好的表示**里隐含的结构"读出来"。表示里没有结构（因为没学好），它读出来的就是噪声。

**所以：元训练负责把任务结构解出来，非参数精炼负责利用无标签几何；两者不可互相替代。**

### 【公平性说明（必答的质疑）】

**质疑**："标签传播用了查询集的输入（直推式），而纯监督没用，这不公平。"

**回应**：所有内循环 SSL 变体（`sup_ent`/`sup_lp`/`ssl_ent`/`ssl_lp`）**同样能看到查询集的输入**（它们也都在查询输入上算无标签损失）。在这个**同等信息访问权**下，最高的内循环变体也只有 79.44% < 82.64%。

**所以"放在适应之后更好"这个结论，不是因为多看了数据。**

### 【代码位置】

```python
# exp1_synth.py 的求值函数：同一个 eval 里区分三种位置
if method in ("sup", "sup_ent", "sup_proto", "sup_lp"):
    inner = make_inner(net, task, kind, cfg)         # 位置①：内循环
    thetas = inner_adapt(P0, inner, cfg["alpha"], steps)

# 位置③：先纯监督适应，再用无标签做精炼
thetas = inner_adapt(P0, lambda P: ce_grad(net, P, Xs, ys), cfg["alpha"], steps)
Pf = thetas[-1]
F = net.features(Pf, np.vstack([Xs, Xq]))
Y = label_propagation(F, ys, idx, task.n_way, k=cfg["lp_k"], alpha=cfg["lp_alpha"])
```

## 5.2 三段式：我们的方案

$$\underbrace{\theta_0=\mathrm{MetaTrain}(p(\mathcal T))}_{\text{① 给起点}}\;\longrightarrow\;\underbrace{\theta_s=\mathrm{Anchor}(\theta_0,\;K\ \text{个标签})}_{\text{② 钉锚点}}\;\longrightarrow\;\underbrace{\hat y=\mathrm{Refine}_{\text{SSL}}(\theta_s,\;U)}_{\text{③ 放大无标签}}$$

### 【这个设计如何正面回应项目核心问题①】

| 项目问题 | 我们的回答 |
|---|---|
| 如何在 inner loop 中引入无标签数据 | **我们检验后发现不应放进 inner loop**，改为三段式：元训练给起点 → K 标签适应 → **适应之后**做半监督 |
| 如何抑制伪标签误差向 meta-gradient 传播 | **结构上消除**：第三段发生在元梯度**之后**，没有二阶求导路径 |
| 如何抑制伪标签误差累积 | 三个手段：**EMA 教师**（伪标签不来自当前模型）、**ramp-up 小权重**、**源域选参**（不碰目标域标签） |

### 【第三段的强度应当由信息量决定，而不是固定超参】

我们实测：
* 同分布划分下第三段增益 ≈ 0
* 跨区域划分下 −11.5%
* 合成簇状任务下 +6.78 点

**判据是：无标签数据相对于元训练先验的"新增信息量"。** 详见第十章"预测 1"。

## 5.3 真实数据上的落地验证

### 【数据 · USGS 真实水数据集（37 站 × 705 天 × 11 指标，次日 pH 回归）】

| 设定 | 纯监督 MSE | **Pseudo-Label MSE** | 配对 ΔMSE | 相对 |
|---|---|---|---|---|
| 随机站点划分 K=10 | 0.378 | **0.299** | −0.0792 ± 0.0165 | **−20.9%** |
| 随机站点划分 K=30 | 0.387 | **0.294** | −0.0935 ± 0.0459 | **−24.1%** |
| 空间划分 K=30 | 0.283 | **0.250** | −0.0333 ± 0.0066 | **−11.8%** |

**【白话】** MSE = 预测误差的平方平均，**越低越好**。把 Pseudo-Label 放在**适应之后**，真实数据上预测误差降低 **11.8% ~ 24.1%**，三种划分下都成立。

### 【关键工程发现：回归下 Pseudo-Label 的零梯度陷阱】

**Pseudo-Label 直接用在回归上，梯度恒等于 0。** 因为如果老师就是学生自己、又没停梯度：

$$\|f_\theta(x)-f_\theta(x)\|^2\equiv0$$

**我们实测过**：paired ΔMSE = **+0.00000 ± 0.00000**（精确为零，是退化的指纹）。

**解决办法：用滞后的 EMA 教师**（Mean Teacher 那一套）：

$$\mathcal L=\big\|f_\theta(x)-\mathrm{sg}\big[f_{\theta_{\text{ema}}}(x)\big]\big\|^2,\qquad \theta_{\text{ema}}\leftarrow\beta\theta_{\text{ema}}+(1-\beta)\theta$$

**【白话】** 别用"我现在的答案"当标准答案（那等于没学），要用"我最近一段时间平均下来的答案"当标准答案——它更稳定。

### 【对照：另两个方法在这份数据上无效】

| 方法 | 源域 λ 扫描（源域验证 MSE） | 选出的最优 λ |
|---|---|---|
| **Pseudo-Label** | 0.2531 → 0.2263 → 0.2004 → **0.1705**（λ 越大越好） | **1.0** |
| FixMatch 回归形式 | 0.2531 → 0.3295 / 0.3793（全部变差） | **0.0（别用）** |
| VAT 回归形式 | 0.2531 → 0.2873 / 0.4393（全部变差） | **0.0（别用）** |

**这排除了"你只是没调好"的可能——是网格搜索自己得出了"不要用它"的结论。**

# 第六章 · 理论副产品：VAT 的秩退化 ⭐必讲（论文亮点）

## 6.1 【要证明什么】

VAT 的核心卖点"选择最各向异性方向"，在输出维度不足时**不存在**。

## 6.2 【依据 · 论文原文】

> "Our proposed regularization technique is a method that trains the output distribution to be isotropically smooth around each input data point **by selectively smoothing the model in its most anisotropic direction**."

## 6.3 【我们的命题】

对 softmax 模型，记 $z(x)\in\mathbb R^C$ 为 logit，$p=\mathrm{softmax}(z)$，则

$$H:=\nabla^2_r\,D_{KL}\big(p(y|x)\,\|\,p(y|x+r)\big)\Big|_{r=0}$$

是半正定矩阵，且

$$\boxed{\ \mathrm{rank}(H)=\min\big(I,\ C-1\big)\ },\qquad H=\sum_{k}p_k\,(g_k-\bar g)(g_k-\bar g)^\top,\quad g_k=\nabla_x z_k,\ \ \bar g=\textstyle\sum_j p_j g_j$$

### 【证明要点】

把 $D(r)$ 对 $r$ 求二阶导。含 $\partial^2 z/\partial r^2$ 的那一项的系数是

$$\sum_c p_c(p_k-\delta_{ck})=p_k\sum_c p_c-p_k=p_k-p_k=0\quad(\text{对每个 }k\text{ 都成立})$$

**恒为零**；剩下的项恰是中心化 logit 梯度的加权协方差，即上式。其秩至多为 $C-1$（因为有 $\sum_k p_k(g_k-\bar g)=0$ 一条线性约束），也至多为 $I$。

## 6.4 【两个推论】

| 任务 | 秩 | 后果 |
|---|---|---|
| **二分类**（C=2） | **1** | $H=p_0p_1(g_0-g_1)(g_0-g_1)^\top$，$r_{\text{vadv}}=\epsilon\cdot\nabla_x(z_1-z_0)/\|\cdot\|$ → **精确等价于"无监督 FGSM"**，幂迭代冗余 |
| **标量回归** | **1** | 取 $D(r)=(f(x+r)-f(x))^2$，则 $H=2\nabla_xf(\nabla_xf)^\top$ |

**秩为 1 意味着方向唯一，"选择"不存在。**

## 6.5 【数值验证】

### 二分类（合成任务 + 真实水数据骨干）

| 样本 | rank(H) | λ₁ | 解析预测 $p_0p_1\|g\|^2$ | 特征向量与 $g$ 的 $\lvert\cos\rvert$ | 相对误差 |
|---|---|---|---|---|---|
| 0 | **1** | 4.8664 | 4.8664 | **1.000000** | 8.1e−09 |
| 1 | **1** | 1.0856 | 1.0856 | **1.000000** | 2.0e−08 |
| 2 | **1** | 0.7923 | 0.7923 | **1.000000** | 5.1e−09 |

单步 VAT 方向与归一化间隔梯度的**逐样本 $\lvert\cos\rvert$ = 1.000000**。

### 标量回归（真实水数据骨干）

| 样本 | rank(H) | λ₁ | 解析预测 $2\|\nabla f\|^2$ | $\lvert\cos(u,\nabla f)\rvert$ | 相对误差 |
|---|---|---|---|---|---|
| 0 | **1** | 998.5321 | 998.5321 | **1.000000** | 4.1e−12 |
| 3 | **1** | 1024.4213 | 1024.4213 | **1.000000** | 4.4e−12 |
| 6 | **1** | 994.9301 | 994.9301 | **1.000000** | 2.7e−12 |

### $C$ 的依赖（$I=6$）

| $C$ | 2 | 3 | 5 | 10 |
|---|---|---|---|---|
| rank(H) | 1 | 2 | 4 | 6 (= $I$) |
| $\min(I,C-1)$ | 1 | 2 | 4 | 6 |

**秩与公式精确吻合。**

## 6.6 【白话】

VAT 说"我要挑模型最怕被晃的那个方向"。但**如果模型只有一个方向可晃**，那"挑"就没意义了——**它退化成"沿着预测梯度方向加噪声"**。

**而且这不是调参能改变的，是数学结论。**

## 6.7 【使用边界与对项目的意义】

**使用边界：VAT 只在多分类（$C\ge3$）或高维输出时才真正有用。**

**对项目的意义 → 见第十章"预测 2"**：建议把黄河项目的目标离散成 3–5 档做多分类，这样 VAT 才会显示出相对"各向同性噪声（RPT）"的优势。**这是一个可直接证伪的预测。**

# 第七章 · 工程框架：统一接口（回应项目核心问题②）⭐必讲

## 7.1 设计目标（项目原文）

> "现有小样本学习和半监督学习算法相对独立，数据组织与实验流程也不统一。如何抽象统一的算法与数据接口，设计可配置的任务采样和数据加载机制，使不同算法能够在统一框架下运行，并在真实数据接入时避免大规模重构。"

## 7.2 三层结构

```
┌─────────────────────────────────────────────────────────────┐
│ 第三层  实验配置层  exp1_synth.py / exp2_water.py / ...      │
│         只声明：任务分布、方法名、超参、评价指标              │
├─────────────────────────────────────────────────────────────┤
│ 第二层  算法层      ml/core.py（元学习）  ml/ssl.py（半监督） │
│         统一接口：一个"损失项" = 函数 P -> (loss, dP)        │
├─────────────────────────────────────────────────────────────┤
│ 第一层  数据层      ml/tasks.py（任务采样器） matio.py（读入）│
│         统一接口：sample_task(rng, **cfg) -> Task            │
└─────────────────────────────────────────────────────────────┘
```

## 7.3 关键抽象（框架的核心）

把每一个损失项都写成

```python
def term(P) -> (loss: float, dP: list[(W, b)])
```

**【白话】** "**给我参数，我给你损失和梯度**"这样一个函数。

**好处：同一个半监督项可以不加修改地放到三个不同位置**：
* 放进 `inner_adapt` 的梯度函数里 → **内循环融合**（第三章）
* 加进外层 meta-objective → **元正则**（第四章 M3 的验证）
* 放在适应之后单独优化 → **后置精炼**（第五章）

**这正是我们做"半监督信号该放哪里"这个科学问题所需要的可插拔能力。**

## 7.4 已实现模块清单

| 模块 | 内容 | 对应能力 |

# 第八章 · 面向黄河项目的理想方法设计 ⭐必讲

## 8.1 方法总体架构

```
                  ┌─────────────────── 阶段① 给起点 ───────────────────┐
黄河多源数据 ──▶ 任务构造 ──▶ 元训练（MAML / 一阶近似）──▶ θ₀
                   │                                        │
                   │  可选：在外层加半监督正则 λ'·L_U(θ')    │（实测 +3.6 点）
                   └────────────────────────────────────────┘
                                    │
                  ┌─────────── 阶段② 钉锚点 ───────────┐
                  │  新任务/新断面：K 个已标注时间点      │
                  │  短内循环（1–5 步，α 小，可只调头部） │──▶ θ_s
                  └────────────────────────────────────┘
                                    │
                  ┌────────── 阶段③ 放大无标签 ──────────┐
                  │  Pseudo-Label + EMA 教师              │
                  │  λ 从 0 ramp-up 到 λ*（源域选）       │──▶ ŷ
                  │  （可选）时间序列强增广一致性          │
                  └────────────────────────────────────┘
```

## 8.2 任务定义（黄河场景的具体化）

| 层级 | 任务 = | 数量级 | 用途 |
|---|---|---|---|
| **站点级** | （断面 × 指标）的时间序列预测 | 数十~数百 | 基础单元 |
| **区域级** | （子流域 × 季节）× 指标 | 10² ~ 10³ | 元训练主任务池 |
| **情景级** | （丰水年/枯水年 × 区域） | 10² | 分布偏移测试 |

* **support**：该任务上 K 个已标注时间点（K ∈ {5,10,20,50}）
* **unlabeled**：同一测站/断面**全部**已有的协变量记录（气象、遥感），**这才是稀缺标签条件下的真实资源**
* **query**：留出的未来时段
* **元训练/元测试划分**：**按断面或子流域划分**（不是按时间随机划分），这样才能制造真实的分布偏移——我们的实验显示，**没有分布偏移时第三段几乎无增益，有偏移时增益显著**。

## 8.3 阶段③ 的具体算法（推荐配置）

```
输入：θ_s（适应后的模型）、无标签序列 U、有标签集 D_l
超参：λ*（源域选，本数据上 λ*=1）、β=0.99（EMA 衰减）、ramp 比例 = 20%

θ_ema ← θ_s
for step in 1..T:
    # 1) EMA 教师给出伪标签（关键：不是用当前模型）
    y_pseudo ← f_{θ_ema}(x_u),   x_u ~ U
    # 2) 学生拟合伪标签；权重从 0 线性升到 λ*
    L ← L_sup(D_l) + λ(step) · ||f_θ(x_u) − sg[y_pseudo]||²
    θ ← Adam_step(θ, L)
    # 3) 更新教师
    θ_ema ← β·θ_ema + (1−β)·θ
return θ
```

**三个防误差累积的设计（直接回应问题①后半句）**：
1. **EMA 教师**：伪标签来自参数平均的历史模型，比当前模型稳定；也避免"目标=预测"导致的零梯度退化。
2. **ramp-up + 小权重**：一开始几乎不自训练，等模型稳定后再加大。
3. **早停 + 源域选参**：在留出的**源域任务**上选 λ 与步数，完全不碰目标域标签。

## 8.4 时间序列特有的增强设计（下一阶段的改进点）

**【诚实说明】** 我们的"FixMatch 有害"结论是在**表格/标量回归**数据上做的，那里"强增广"没有语义。**时间序列不一样**——以下是时间序列上语义有意义的强增广：

| 弱增广 | 强增广 |
|---|---|
| 小幅高斯噪声 | **时间扭曲 (time warping)**、**窗口裁剪/缩放 (window slicing)**、**幅度缩放 (magnitude scaling)**、**随机遮挡片段 (cutout)**、**通道丢弃** |

**所以"带强增广的 FixMatch"值得在黄河数据上重测**——这是我们下一阶段的实验点，而不是直接下结论。

## 8.5 与项目两个核心问题的对应关系

| 项目提出的问题 | 我们的回答 |
|---|---|
| ① 如何在 inner loop 中引入无标签数据、抑制伪标签误差向 meta-gradient 传播 | **我们检验后发现不应放进 inner loop**。改为三段式：元训练给起点 → K 标签适应 → **适应后**做 Pseudo-Label(EMA)。这样伪标签误差**在结构上无法流入 meta-gradient**；误差累积用 EMA 教师 + ramp-up + 源域选参抑制。给出了机理（$O(\alpha m)$ 任务特异性、退化解、时间尺度）与实验证据。 |
| ② 统一算法与数据接口、真实数据接入不重构 | **已实现三层框架**：损失项统一为 `P -> (loss, dP)`，可插拔到内循环/外层/适应后三个位置；任务采样统一为 `sample_task -> Task`；已用合成、公开、真实三类数据验证，接入新数据只需写 1 个 loader + 1 个采样器。 |

## 10.2 两个可证伪的预测（论文核心论断）

### 预测 1 · 第三段的增益随"分布偏移"单调上升

**我们的观察**：合成簇状任务 **+6.78 点** > 跨区域划分 **−11.5%** > 同分布划分 **≈0**。

**白话**：当训练过的站点和要预测的新站点**差别越大**时，新站点的无标签记录**包含的"新信息"就越多**，第三段就越有用。反过来，如果新老站点差不多，模型早就学会了，无标签数据也就没什么可提供的。

**验证方式**：在黄河数据上按断面/子流域划分任务，画"第三段增益 vs 偏移强度"曲线。

### 预测 2 · 把目标离散成 3–5 档多分类后，VAT 才会显示出相对各向同性噪声的优势

**依据**：第六章的秩定理——二分类和标量回归下 $\mathrm{rank}(H)=1$，多分类下 $=C-1\ge2$，方向才真正有得选。

**验证方式**：把 pH 或径流离散成 3–5 档，对比 VAT 与 RPT（同范数各向同性噪声）。

# 第十一章 · Q&A 预案 ⭐必讲

**Q1：你的负面结论会不会只是因为实现或调参不到位？**
A：做了三层排查。
(1) **实现正确性**：元梯度用有限差分校验，二阶元梯度相对误差 **1.8×10⁻⁵**；VAT 的秩定理用解析式 + 数值 Hessian 双向验证（相对误差 ~1e−12）；"冻结教师"项在 m=1 时**精确等于 0.00**（代码自检）。
(2) **调参**：每个方法在**源域验证集**上单独做网格搜索，FixMatch/VAT 的最优 λ 就是 0——**是搜索自己得出"不用它"的结论**。
(3) **机理**：给出 $O(\alpha m)$ 分析并用 $(\alpha,m)$ 扫描直接检验，结果与预测一致（小 $\alpha m$ 无影响、大 $\alpha m$ 急剧掉点）。

**Q2：那半监督到底有用吗？**
A：有用，但位置要对。适应之后做 Pseudo-Label 在真实水数据上降 **11.8%–24.1% MSE**（2–5 个标准误）。我们反对的是"塞进 inner loop"，不是"用半监督"。

**Q3：为什么 Pseudo-Label 最好，而不是理论上最优雅的 VAT？**
A：VAT 的优雅来自"选择最各向异性方向"。但我们的秩定理说明：分类秩为 $\min(I,C-1)$、标量回归秩为 1，**输出维度不足时方向唯一，"选择"不存在**。而且表格/数值特征上 L2 球的邻域没有语义。Pseudo-Label 恰好是三者中对数据前提要求最少的（不需要增广、不需要阈值、不需要输入邻域语义）。

**Q4：Pseudo-Label 用自身预测做目标，梯度不是 0 吗？**
A：**对，直接用在回归上梯度恒等于 0**（我们第一版实测 ΔMSE 精确为 0.00000）。所以必须用**滞后的 EMA 教师**给出伪标签——这就是 Mean Teacher 的做法，也是回归下 Pseudo-Label 唯一非退化的形式。这一点在分类里被 argmax 的非线性掩盖了，容易被忽略。

**Q5：你的方法和小样本领域的已有工作（Ren et al. 2018 的 soft k-means、LST、TPN）有什么区别？**
A：
(1) **Ren et al. 2018** 是在 **ProtoNet 的 episode 内**做闭式 soft k-means 精修，**不做梯度 inner loop、也不对比 MAML**；我们的贡献是把"SSL 在 MAML 内循环里"这个具体路线做了干净对比并给出机理。
(2) **LST (NeurIPS 2019)** 已经用了三段式（预训练 → 元训练 → 测试期循环自训练 + 软权重网络），我们是独立得到同样方向并补充了机理与真实时空数据验证。
(3) **TPN (ICLR 2019)** 元学习的是**图构造**，不是把传播放进梯度内循环。

**Q6：这个问题为什么值得做？**
A：因为"在 inner loop 里加半监督项"在框架层面是合法的（MAML 原文只要求损失对参数可微），所以很多人会默认它有效。我们证明了它在这个设定下有系统性障碍，并给出了正确的替代设计——**避免后续工作在这条路上重复投入**。这类"定位失效边界"的结果在方法类论文里是被认可的。

**Q7：时间序列上 FixMatch 会不会不一样？**
A：**可能会，这正是我们下一步要测的。** 我们的"FixMatch 有害"结论来自缺语义增广的表格回归；时间序列有真正的强增广（时间扭曲、窗口裁剪、幅度缩放），这些是语义有意义的。所以我们把"带强增广的 FixMatch"列为下一阶段实验，而不是直接下结论。

**Q8：第三段的增益会不会只是过拟合？**
A：不会，因为：
(1) 我们报告的是**配对差**（同一站点、同一 seed 下 method − sup），标准误很小（空间划分下 ±0.0066，约 5 个标准误）；
(2) 超参在**源域**选，不碰目标域标签；
(3) 训练过程无早停、无目标域验证集，是纯半监督协议。

**Q9：这份材料里的数据都是你自己跑的吗？**
A：是的，全部可复现。代码在 `ml/` 与 `exp1`–`exp5`，结果 JSON 与渲染脚本都在 `reports/`，元梯度与秩定理都有独立校验脚本。
