# 结论是怎么推出来的：「半监督信号不该放进 MAML 的 inner loop」

## 第 0 步 · 先把术语说清楚（看不懂后面任何东西时回来查这张表）

| 术语 | 英文 | 白话解释 |
|---|---|---|
| **任务 / episode** | task / episode | 一次小样本学习问题。比如"我给你 5 个类别各 1 个样本，你学会区分这 5 类"。**一个任务 ≈ 一局游戏。** |
| **支持集** | support set, $D$ 或 $D_S$ | 这一局里**有标签**的少量样本，模型用它来"适应"这个任务 |
| **查询集** | query set, $D'$ | 同一局里**另一批有标签**样本，只用来给"适应得好不好"打分（算元损失） |
| **无标签池** | unlabeled pool, $D_U$ | 只有输入、没有答案的数据 |
| **内循环 / 适应** | inner loop / adaptation | 拿支持集对模型做几步梯度下降，得到**只属于这一局**的参数 $\theta'$ |
| **外循环 / 元更新** | outer loop / meta-update | 在所有局上评价 $\theta'$，把梯度回传去更新**所有局共用的初始参数** $\theta$ |
| **初始化** | initialization, $\theta$ | 一个"离所有任务的好答案都很近"的起点 |
| **元梯度** | meta-gradient | $\nabla_\theta L(\theta')$：**对共享参数 θ 求导、在适应后的 θ' 处取值**。因为 $\theta'$ 本身含 θ，所以导数要穿过"梯度"这一层，出现二阶项 |
| **二阶 / Hessian 向量积** | second-order, HVP | 上面提到的"穿过梯度求导"具体要做的事 |
| **一阶近似 FOMAML** | first-order MAML | 把那个二阶项直接丢掉，省一次反传 |
| **伪标签** | pseudo-label | 模型自己预测出来的标签，冒充真标签来用 |
| **置信度阈值** | confidence threshold $\tau$ | 只采信"模型很有把握"的伪标签，其余丢掉 |
| **课程** | curriculum | 训练早期少用无标签数据、后期逐步放开的学习节奏 |
| **熵最小化** | entropy minimization | 逼模型输出更"确定"（概率分布更接近 one-hot，比如 [0.98, 0.02] 而不是 [0.6, 0.4]） |
| **退化解** | degenerate solution | 目标函数的最优解是"模型塌成一个常数""所有点都推给同一类"这类**没意义但损失很低**的解 |
| **确认偏误** | confirmation bias | 错误的伪标签被反复强化，越错越深 |
| **任务特异 / 任务无关** | task-specific / task-agnostic | 这个量是**只属于当前这一局**的，还是**所有局共享**的 |
| **消融实验** | ablation | 只去掉一个部件、其他全不变，看性能变化，用来判断这个部件到底有没有用 |
| **配对差** | paired difference | 同一局、同一随机种子下"方法 A 减方法 B"，这样能消掉局的难度差异，只看方法差异 |
| **标准误 (SE)** | standard error | 多次重复实验里"均值"本身的波动范围。差值是标准误的 2 倍以上，才通常认为不是碰巧 |

## 第 0.5 步 · 怎么读后面的表格（先看这个，后面就不迷路）

**所有表格都是准确率，单位 %，越高越好。**

* **一张表里的行 = 不同"元训练方式"**（也就是"起点怎么来的"）
* **一张表里的列 = 不同"无标签数据怎么用"**

**关键读法**：不要横向比不同行（那是不同起点，没法比），要**在同一行里横向比**——"同样的起点下，加不加某个半监督项"。这才是我们要的对比。

比如：

| 主干 | 只做监督适应 | +熵最小化 | +原型蒸馏 |
|---|---|---|---|
| MAML 二阶 | **75.86** | 63.05 | 71.64 |

**正确读法**：在"起点是 MAML"这一行里，不加 SSL 是 75.86，加了熵最小化掉到 63.05（**−12.81**），加了原型蒸馏掉到 71.64（**−4.22**）。→ **同样的起点，加 SSL 就变差。**

**错误读法**（不要这样看）："FOMAML 的 78.94 比 MAML 的 75.86 高，所以 FOMAML 更好"——这两行是不同的起点，它们的差别是另一件事（一阶近似 vs 二阶）。

## 第 1 步 · 这个想法从哪来：MAML 论文自己留了一个口子

**逻辑**：先确认"把半监督放进内层"在**框架层面是否合法**。如果合法、而论文又没试过，那才值得做。

### 论文原文（MAML, ICML 2017）

> "We make no assumption on the form of the model, other than to assume that it is parametrized by some parameter vector θ, and that **the loss function is smooth enough in θ** that we can use gradient-based learning techniques."
>
> （我们对模型形式不做假设，只假设它由参数 θ 参数化、且**损失函数对 θ 足够光滑**以便用梯度法。）

> Algorithm 2 第 6 行："Evaluate $\nabla_\theta L_{T_i}(f_\theta)$ using $D$ and **$L_{T_i}$ in Equation (2) or (3)**"

—— 这句话把**损失函数当成一个可替换的插件**（式 2 是 MSE，式 3 是交叉熵）。

> "The step size α may be fixed as a hyperparameter or meta-learned."

> "since our method merely produces a weight initialization, **adaptation can be performed with any amount of data and any number of gradient steps**"

### 【白话】这三句话在说什么

MAML 的算法骨架其实非常朴素：

```
第 5 行：从这个任务里抽 K 个有标签样本，叫支持集 D
第 6 行：用 D 算一下当前参数的梯度          ← "损失函数"在这里插进去
第 7 行：沿着梯度走一步，得到 θ'（这一步叫"适应"）
第 8 行：再从同一个任务里抽另一批有标签样本 D'，用 θ' 算损失
第 10 行：把这个损失对最初的 θ 求导，更新 θ（这一步叫"元更新"）
```

**关键就是第 6 行那个"损失函数"**：论文写的是"用式(2)或式(3)"，式(2)是回归用的 MSE，式(3)是分类用的交叉熵。也就是说，**损失函数在这里是一个可以替换的零件**。

那自然就会想：**我能不能在这个位置再加一项？**

$$\theta'=\theta-\alpha\nabla_\theta\underbrace{\big[L_S(\theta;D)+\lambda L_U(\theta;D_U)\big]}_{\text{原来的 }L_S\text{ + 我加的半监督项}}$$

* $L_S$ = 支持集上的监督损失（原来的）
* $L_U$ = 无标签数据上的损失（我加的）—— 比如"让模型对无标签数据自信一点"（熵最小化）、"让模型的预测和标签传播的结果一致"（LP 蒸馏）
* $\lambda$ = 这一项占多大权重

而且论文还明确说"损失只要对 θ 光滑就行"、"适应阶段可以用任意多数据、任意多步"——**听起来完全是允许的**。

### 关键事实

**MAML 全文没有出现 "unlabeled"、"semi-supervised" 这两个词。** 论文从没做过任何"内层加额外损失项"的实验。

### 【白话】结论

$$\boxed{\text{内层损失是一个"插件接口"} \;\wedge\; \text{论文从未试过半监督} \;\Longrightarrow\; \text{这是一个真实的研究空白}}$$

翻译成人话：**论文留了一个口子，但自己没往里塞过东西。所以值得试。**

**顺带一提**：VAT 论文自己就承认"忽略一部分依赖"是可以接受的近似——
> "Our VAT therefore **ignores the dependency of $r_{vadv}$ on θ**."

这说明"元梯度忽略一部分依赖"在文献里是被允许的，进一步给人信心"内层可插"。

## 第 2 步 · 把假设写成可检验的形式

**逻辑**：不能只说"我想试试"。要写成**能被实验否证**的假设，否则最后只能得到"不行"这种很弱、很容易被质疑的结论。

记内层步长 $\alpha$、步数 $m$。

$$\textbf{H}_0:\quad \theta'=\theta-\alpha\nabla_\theta\big[L_S+\lambda L_U\big]\ \text{ 比 }\ \theta'=\theta-\alpha\nabla_\theta L_S\ \text{ 更好}$$

### 【白话】怎么把一句"想法"变成"能打脸的假设"

**H₀（零假设）**就是一句大白话：**"在内层加上半监督项，效果会更好。"**

但光这么说没法做实验——因为做完了如果变差，别人会说"那只是你没调好"。所以要从 H₀ 里推出**两个具体的、可以量化观察的预言**：

| 预言 | 如果 H₀ 成立，应该观察到什么 | 为什么这算"预言" |
|---|---|---|
| **预言 A** | **至少某一种**半监督项应该带来正增益（不可能三种全负） | 因为半监督方法有很多种，如果"内层这个位置对"，总该有一种能work |
| **预言 B** | 因为任务特异的部分随 $\alpha m$ 增大而增大，所以**把信号先调小、再逐渐调大，应该看到"先变好、后变差"** | 就像调音量：太小听不见，太大破音，中间最好 |

**这两条就是后面用来打脸的武器。** 只要有一条不成立，H₀ 就被否证；如果两条都不成立，结论就很硬。

### 【白话】预言 B 在说什么

* $\alpha$ 是"每次走多远"，$m$ 是"走几步"，$\alpha m$ 大致就是"**参数总共移动了多远的距离**"。
* **移动距离小** → 模型还是原来那个通用模型，伪标签没变化 → 半监督项几乎不起作用（应该是"没效果"）
* **移动距离适中** → 模型开始带上"这一局"的特色，伪标签开始变得任务相关 → 半监督项应该开始有用（**应该"变好"**）
* **移动距离很大** → 模型已经彻底变成这一局的专用模型了，甚至过拟合 → 半监督项可能又开始捣乱（"变差"）

**所以如果 H₀ 成立，曲线应该是个"倒 U 形"：先升后降。** 我们后面就是拿这个形状去检验的。

### 代码位置

```python
# ml/core.py
def inner_adapt(P, inner_grad, alpha, steps):
    """返回 [theta_0, theta_1, ..., theta_steps]"""
    thetas = [p_clone(P)]
    for _ in range(steps):
        _, g = inner_grad(thetas[-1])          # ← 这里就是"插件接口"
        thetas.append(p_sub(thetas[-1], g, alpha))
    return thetas

# exp1_synth.py
def make_inner(net, task, kind, cfg):
    base = lambda P: ce_grad(net, P, task.Xs, task.ys)     # L_S
    if kind == "ssl_ent":
        U = make_entropy_term(net, task.Xu)                # L_U：熵最小化
        return lambda P: combine_grads(base(P), scale_term(U(P), cfg["lam"]))
    if kind == "ssl_proto":
        U = make_proto_distill_term(...)                   # L_U：原型蒸馏
        ...
```

### 【白话】这段代码

* `inner_grad` 是一个**函数**，你给它参数，它返回"这个参数下的损失和梯度"。
* `inner_adapt` 就是"拿着这个函数走 m 步"。
* **换掉 `inner_grad`，就等于在换"内层到底优化什么"。** 这就是"插件接口"的代码体现。

`make_inner` 里那个 `if kind == ...` 就是在选择"这一局往内层塞什么"：
* `"ssl_ent"` → 塞熵最小化
* `"ssl_proto"` → 塞原型蒸馏
* 什么都不塞（走默认分支）→ 就是纯监督

## 第 3 步 · 实验怎么设计的（**这一节是理解全部实验的钥匙**）

### 3.1 先说清楚：一局"5-way 1-shot 分类任务"到底是什么

**术语拆解**：
* **5-way** = 5 个类别
* **1-shot** = 每个类别只给 **1 个**有标签样本
* 所以整个支持集只有 **5 个点**（每类一个）——这就是"标注样本极少"的极端情形

**一局的流程**（用二维平面就能想象出来）：

1. 在平面上撒 5 个"类中心"；
2. 每个类中心周围按高斯分布生成一堆样本点（带随机扰动）；
3. 从每一类里各抽 1 个点当**支持集**（共 5 个点，带答案）；
4. 其余所有点当**查询集**（有答案，但只用来打分，不参与训练）。

**模型的活儿**：只看那 5 个带标签的点，把查询集的每一个点判断出属于哪一类。

### 3.2 为什么"普通的簇状高斯任务"回答不了我们的问题

**【白话】如果就这么简单，会发生什么？**

假设样本就是 `[x1, x2]` 两个数，5 个类各自聚成一团。那么：

* 查询集的点**自己就聚成 5 团**（因为每一类是一个高斯团）；
* 每个支持点**必然落在其中一团里**；
* 于是"把每一团贴上对应支持点的标签"就完事了 —— **这就是标签传播**，它**根本不需要神经网络学什么表示**。

**后果**：无论你把半监督项放在内层还是外层，结果**都好**，实验没有区分度，也说明不了任何问题。这种情况下的结论会退化成一句废话："**SSL 都能用**"。

**所以必须改造任务，让"表示学得好不好"变成决定成败的关键变量。** 我们加了两条设计。

---

### 3.3 设计 1：加 6 个噪声维度

#### 【白话】具体是怎么改的

**改之前**：每个样本是 2 个数 → `[x1, x2]`
**改之后**：每个样本是 8 个数 → `[x1, x2, n3, n4, n5, n6, n7, n8]`

* **前 2 维 $(x_1,x_2)$**：承载**类别结构**，也就是真正有用的"信号"
* **后 6 维 $(n_3 \dots n_8)$**：纯噪声，从标准正态分布 $N(0,1)$ 随机抽出来，**和这个样本属于哪一类完全无关**

#### 【白话】关键在"尺度对比"

| | 大小 |
|---|---|
| **信号**：类中心分布在一个**半径 1** 的圆上，同类样本围绕中心波动，标准差 **σ = 0.35** | 也就是"有用信息的幅度"约 0.35 |
| **噪声**：6 个维度，每个都是从 $N(0,1)$ 抽的，标准差 **1.0** | 也就是"噪声的幅度"约 1.0 |

那么两个样本之间的欧氏距离（也就是"它们有多像"），**绝大部分来自那 6 个噪声维度**，真正决定类别的 2 个维度只贡献一点点。

**打个比方**：你想判断两个人的相似度，本来只需要看身高体重（2 个有用指标），但我又给你加了 6 个完全随机的骰子点数（今天掷出多少完全随机，和这两个人是谁无关）。你算"距离"的时候，骰子点数的差异会把身高体重的差异彻底淹没。**你量到的基本上都是骰子。**

#### 【白话】后果

**如果你直接在原始 8 维输入上算距离做标签传播，你量到的基本上都是噪声，传播就是瞎猜。**

实测结果印证了这一点：**31.33%**（5 分类完全随机是 20%）。

> 为什么不是正好 20%？因为那 2 个信号维度还在，多少提供了一点信息；但 31% 距离"能用"差得很远。

#### 【白话】这就逼出了元学习的价值

只有当模型学会 **"把 8 维压缩成 2 维、把 6 个噪声维度扔掉"**，标签传播才有意义。

**于是"表示学得好不好"就成了区分不同方法的关键变量**——这正是我们要研究的。

#### 我们有数据证明这一点（同一批任务上的四种做法）

| 做法 | 标签传播的准确率 | 白话 |
|---|---|---|
| 不用网络，直接在原始 8 维上传播 | **31.33%** | 被噪声淹没，接近瞎猜 |
| 用**随机初始化**网络提的特征传播 | **31.06%** | 网络没训练，提的特征也是乱的 |
| 用**普通预训练**（联合训练）网络提的特征传播 | **25.23%** | 居然更差——因为普通预训练学的是"平均意义上好"，不是"容易区分" |
| 用 **MAML 元训练**网络提的特征传播 | **82.64%** | **只有它学会了扔掉噪声** |

**前三行都在 25%~31% 徘徊（等于没用），只有第四行跳到 82.64%。** 这直接证明了：**在这个任务上，表示必须靠元学习获得，SSL 只有在好表示之上才有意义。**

### 3.4 设计 2：任务特异性（相位随机 + 各向异性变换）

这个设计的目的是：**让模型不能"死记硬背"，必须"每局现推"。**

#### （a）类均值圆环

**【白话】** 5 个类中心不是随便撒的，而是**均匀分布在一个圆上**。比如半径 1 的圆，5 个中心的角度分别是 0°、72°、144°、216°、288°：

```
             类0 (0°)
               ●
      类4 ●         ● 类1
              ✕ 圆心
        ●           ●
      类3            类2
```

**为什么要摆成圆环？** 因为这样 5 个类**两两距离都一样**，不存在"某两类天生更容易混"的问题，任务难度是均衡的。

#### （b）相位（phase）随机

**【白话】** 如果每一局里这 5 个类中心**都在同一套位置**，那模型只要记住"角度 0 附近的就是类 0"就行了——**所有局都一样，元学习就没意义了**（等于只有一局）。

所以每一局把整个转盘**随机旋转一个角度** $\psi$：

* **任务 A**：类 0 在 10°，类 1 在 82°，类 2 在 154°……
* **任务 B**：类 0 在 143°，类 1 在 215°，类 2 在 287°……
* **任务 C**：类 0 在 271°，……

**这就是"任务特异性"**：每一局的规则都不一样。

**比喻**：每一局都是"转了不同角度的同一个转盘"。模型不能记住"黄色在哪个方向"，**必须从这一局给的 5 个支持点里，现推"这个转盘转了多少度"**。

这正是小样本学习的本质：**不是记住答案，而是从极少的例子里快速推断出当前任务的规则。**

#### （c）各向异性线性变换（anisotropic linear map）

**【白话】"各向异性"是什么意思？**

* **各向同性（isotropic）**：各个方向一视同仁，比如圆。
* **各向异性（anisotropic）**：**不同方向被拉伸的倍数不一样**，比如椭圆、平行四边形。

**【白话】我们具体怎么做？**

在旋转之外，再对坐标乘一个 2×2 矩阵 $A$，它的两个"拉伸倍数"（奇异值）取 $e^{\pm 0.4}$，大约是 **0.67 和 1.49**。

**举个直观的例子**：如果 $A=\begin{bmatrix}2&0\\0&0.5\end{bmatrix}$，那么

* 点 $(1,0)$ → $(2,0)$：**横着拉长 2 倍**
* 点 $(0,1)$ → $(0,0.5)$：**竖着压扁一半**

原来的圆形分布就被拉成了一个扁的椭圆。

**【白话】为什么要这么做？两个作用：**

**作用一：让"谁和谁近"变得不那么直观。**
拉长方向上距离被放大，压扁方向上距离被缩小。所以**看起来很近的两个点，可能其实属于不同类；看起来很远的两点，可能属于同一类**。单纯的"最近邻"会出错，模型必须学一个更聪明的度量。

**作用二：每局的拉伸方向不同 → 必须靠支持集推断。**
因为每局的 $A$ 都不一样（旋转 + 拉伸都是随机的），模型**不能死记**，只能从支持集里现推。

#### 【白话】为什么"任务特异性"这么重要

**如果所有局都是同样的转盘、同样的拉伸** → 模型可以学到一个固定的解 → **元学习退化成普通监督学习**，整个实验就没意义了。

**加上任务特异性之后** → 模型必须学会"**从少量支持点快速推断当前任务的规则**"——这正是 MAML 被设计出来解决的问题，也是我们要研究的那个能力。

**一句话总结这两个设计**：
> 设计 1（噪声维度）保证"**必须学表示**"，设计 2（任务特异性）保证"**必须靠支持集现推**"。两者合起来，才让"SSL 放在内层还是外层"这件事变成一个**有区分度**的实验。

---

### 3.5 完整配置

5-way **1-shot**（每类只给 1 个标签，支持集共 5 个点）、查询集 75 点、元训练 2500 次迭代 × 每批 16 个任务、元测试 **400 个任务**；网络 8→40→40→5（ReLU）；MAML $\alpha=0.4$、训练 1 步内循环、评测 3 步；二阶用有限差分 HVP（已通过校验，相对误差 1.8×10⁻⁵）。

## 第 5 步 · 检验预言 B：把信号调强，不是变好而是急剧变坏

### 5.1 做法

**先训好一个 MAML 主干**（用 $\alpha=0.4$、1 步训练），然后在**评测时**改变内层的步长 $\alpha$ 和步数 $m$。

**关键**：支持集损失完全一样，唯一差别是"内层里有没有加无标签项"。所以任何差异都只能归因于那个半监督项。

### 【白话】为什么要固定主干、只改评测时的 $\alpha$ 和 $m$

因为我们想验证的是 **"参数移动距离（$\alpha m$）大小"这个变量**，而不是"训练方式"这个变量。

* 如果每个 $\alpha$ 都重新训一个主干，那差异里就混进了"训练方式不同"的干扰；
* 固定主干、只改评测时的 $\alpha,m$，就**只改变了一件事**：内层总共移动多远。

这就是"控制变量"。

### 5.2 数据：内循环熵最小化带来的 ΔAUC（相对同行纯监督基线）

| | m=1 | m=3 | m=8 |
|---|---|---|---|
| **α=0.05** | +0.83 | +0.40 | −0.68 |
| **α=0.1** | +0.19 | −0.09 | −4.35 |
| **α=0.2** | −0.09 | **−12.36** | **−16.69** |
| **α=0.4** | −0.17 | **−12.81** | **−23.33** |
| **α=0.8** | −0.28 | −7.28 | −17.68 |

（表中是"加了熵最小化的准确率 减去 同行纯监督的准确率"，单位是百分点，负号=变差。）

### 【白话】怎么读这张表

* **列** = 内层走几步（m）
* **行** = 内层每步走多远（α）
* **格子里的数** = "加熵最小化"相比"不加"好多少个百分点

**看左上角**：α=0.05、m=1，参数总共只移动了很少 → **+0.83**，基本等于没动（在噪声范围内）。
**看中间**：α=0.2、m=3 → **−12.36**，掉了一大截。
**看右下**：α=0.4、m=8 → **−23.33**，掉得最惨。

### 5.3 【白话】形状说明了什么

我们预期的是"**倒 U 形**"：太小没效果 → 适中变好 → 太大变差。

**实际看到的是：** 只有"死区"（左上角，影响 ≤1 个点）和"断崖"（越往右下掉得越狠）。

**没有"变好"的中间区域。**

$$\boxed{\text{预言 B 被否证：没有"先升后降"，只有"死区 → 断崖"}}$$

**【白话】这为什么重要？**

它排除了一个很自然的辩解："**是不是信号太弱，所以没效果？我把它调强不就好了？**"

实验结果说：**不是。调强之后不是变好，而是急剧变差。**

于是失败的真正原因不再是"力度不够"，而是"**方向错了**"——**它一使劲就往错误的方向推。** 这句话把问题从"工程调参"推进到了"机理"，是整条推理链的转折点。

### 5.4 【白话】表里那个"冻结教师"为什么值得单独提一句

同一张实验里我们还测了另一种内层项："**冻结教师一致性**"——意思是"别偏离起点太远，保持和初始参数 $\theta_0$ 一致"。

在 m=1 那一列，它的效果**精确地等于 0.00**，不是"约等于"，是**严格的 0**。

**为什么？** 因为在 $\theta=\theta_0$ 这个点上，"和初始参数一致"这件事本来就完全满足，损失的梯度也恰好是 0。所以第一步它什么也不做。

**这个 0.00 的意义**：它是一个**代码正确性的自检**——如果我们的实现有 bug，它不可能精确为 0。**这说明实验装置是可靠的，前面的负增益不是代码问题。**

## 第 6 步 · 找机理：为什么内层这个位置天生不适合

四条机理，每条都配论文原文或实验证据。

---

### 机理 M1 · 时间尺度错配（成本层面）

#### 论文原文（FixMatch, NeurIPS 2020）——主实验超参

> "λu = 1, η = 0.03, β = 0.9, **τ = 0.95, µ = 7, B = 64**, K = 2²⁰"

**术语解释**：
* **K = 2²⁰ ≈ 1,048,576** —— 训练总步数（约 100 万步）
* **B = 64** —— 每步用 64 个有标签样本
* **µ = 7** —— 无标签 batch 是有标签的 7 倍，所以每步 7×64 = **448 个无标签样本**

#### 数据：数量级对比

| | 无标签样本消耗量 |
|---|---|
| FixMatch 单次运行 | $448 \times 1{,}048{,}576 \approx 4.7\times10^8$（**4.7 亿**） |
| MAML 内循环（5 步 × 每任务 160 个） | $\approx 800$（**800**） |
| **差距** | **约 6 个数量级（一百万倍）** |

#### 【白话】

自训练、一致性正则这些方法的收益，来自"**反复练很久**"这个**过程**，而不是那个损失函数长什么样。

**打个比方**：FixMatch 是"每天背 448 个单词、坚持 100 万天"；而 MAML 的内循环是"给你 800 个单词、背 5 遍"。

你把一个需要练 100 万步才见效的机制，塞进一个只走 5 步的算子里——**它来不及起作用。**

**这不是"实现问题"，是"预算问题"。**

---

### 机理 M2 · argmax 与阈值构成"零梯度面"（信息层面）

#### 论文原文（FixMatch）

> "we use $\hat q_b = \arg\max(q_b)$ as a pseudo-label"

$$m_b=\mathbb 1\big(\max(q_b)\ge\tau\big)$$

#### 数学事实

**$\arg\max$ 和 $\mathbb 1(\cdot\ge\tau)$ 都是"分片常数"函数**——输入不跨越某个边界时，输出完全不变。

#### 【白话】什么叫"分片常数"、为什么导数为 0

想象一个台阶：你站在第 3 级台阶上，往左挪一点、往右挪一点，**你还是站在第 3 级，高度没变**。只有当你挪得足够多、跨过边缘，才会突然跳到第 2 级或第 4 级。

* **"高度"** = argmax 的输出（类别编号）
* **"位置"** = 模型的参数
* **"没变"** = 导数为 0

**所以：** 元梯度"看不到"该采信哪些样本、也"看不到"阈值该定多少——**因为这些都是台阶，不是斜坡。** 梯度下降只能在斜坡上走。

#### 更要命的是"课程效应"

**FixMatch 论文原文（§2.2）**：
> "This suggests that pseudo-labeling may produce a **natural curriculum 'for free'**."

（模型置信度 $\max(q_b)$ 在训练早期通常小于阈值 $\tau$）

**【白话】"免费课程"是什么意思**

* **训练早期**：模型还很菜，预测的最大概率只有比如 0.6，**低于阈值 0.95** → 这些样本**全部被丢弃** → 无标签损失 = 0
* **训练后期**：模型变强了，最大概率能到 0.97 → **超过阈值** → 这些样本被采用

**所以阈值自动实现了"先易后难"的学习节奏**（这就是"课程"的意思），FixMatch 论文说这是"免费"得到的（不用自己设计课程表）。

#### 【白话】但这对 MAML 内循环意味着什么

内循环只走 1–5 步，参数只移动了 $O(\alpha m)$ 那么一点点。在这个"只轻轻推了一下"的模型上：

$$\max(q_b)\ \text{远小于}\ 0.95 \;\Longrightarrow\; \text{掩码几乎是全 0} \;\Longrightarrow\; \textbf{无监督梯度是空的}$$

**就是说：FicMatch 的这一项在内层根本没生效，权重多大都一样。**

#### 实验印证

我们在一份数据上实测：$\tau=0.95$ 时验证集 AUC 只有 0.61–0.63；把 $\tau$ **降到 0.80** 才回到 0.64–0.65。

**【白话】** 想让它起作用，就必须把阈值降到 0.8 左右。但那样做，**你就已经不是在用 FixMatch 的设计了**（论文的整套超参都是围绕 0.95 调的）。

---

### 机理 M3 · 任务特异性只有 $O(\alpha m)$（**这是核心，也是我最早想通的一步**）

#### 推导

$$\theta'=\theta_0-\alpha\nabla L_S(\theta_0)\quad\Longrightarrow\quad \theta'=\theta_0+O(\alpha m)$$

**【白话】把这一步拆开讲**

**第一步**：梯度下降一步是 $\theta'=\theta_0-\alpha\nabla L_S(\theta_0)$。
* $\alpha$ 是步长（MAML 常用 0.01–0.4）
* $\nabla L_S$ 是支持集上的梯度（支持集只有 5 个点，所以梯度不大）

**第二步**：两项都很小 → **$\theta'$ 离 $\theta_0$ 很近**。用数学符号写就是 $\theta'=\theta_0+O(\alpha m)$，"移动距离和 $\alpha m$ 成正比"。

**第三步（关键）**：**伪标签是由 $\theta'$ 算出来的**。

* 既然 $\theta'$ 几乎就等于 $\theta_0$，
* 那么"$\theta'$ 对无标签数据的预测" $\approx$ "$\theta_0$ 对无标签数据的预测"。

**第四步（最关键）**：**$\theta_0$ 是所有任务共用的！**

$\theta_0$ 是"跨任务共享的起点"——它在所有局里都是同一个。所以由它产生的伪标签，**几乎不包含"当前这一局"的任何特色**。

#### 【白话】把结论用一句比喻说出来

> 你在教一个学生做**这一道题**（当前任务）。但你给的"参考答案"，是从**通用教科书**里抄的（共享起点 $\theta_0$），而不是针对这道题算出来的。

于是你加的这一项 $L_U$，**约束的主要是那本通用教科书（共享参数 $\theta_0$），而不是这道题的具体解法（任务特异的适应）**。

**换句话说：它退化成"在训练时加了一个正则项，防止起点跑太远"，而不是"每个任务各自的半监督适应"。**

#### 【白话】一个数学说明（不用记，理解即可）

"任务特异性只有 $O(\alpha m)$"这句话的意思是：

**内层半监督项对参数的影响里，"所有任务都一样"的部分占了大头，而"属于当前任务"的部分只有 $\alpha m$ 那么小。**

$\alpha m$ 有多小？$\alpha$ 取 0.4、$m$ 取 3，$\alpha m = 1.2$——听起来不小，但它是**相对整套参数的尺度**来说的，而且还要乘上梯度的大小，实际移动量很小（这就是为什么上面那张表里"死区"覆盖了很大一片）。

#### 这一点被实验直接证实（**这是整条链最重要的证据**）

如果 M3 是对的（"内层 SSL 实际上只是在正则化 $\theta_0$"），那么**把它放到外循环（元目标）里也应该有效**。实测：

| 位置 | 效果 |
|---|---|
| 内层（适应项） | 熵最小化 **−12.81** |
| **外层（元正则）** | 熵最小化 **+3.58**（75.86 → 79.44） |

**同一个方法、同一个数据、同一个 $\lambda$，换个位置就从 −12.81 变成 +3.58。**

$$\boxed{\text{这证明问题出在"位置"，而不是"方法"}}$$

---

### 机理 M4 · 退化解（目标层面）

#### 逻辑

按 M3 的结论，把老师改成"**由支持集参数化**"的（原型、标签传播），任务特异性就会变强。**那会怎样？答案是：会塌缩。**

#### 【白话】什么是"老师由支持集参数化"

M3 里说"伪标签来自共享起点，没有任务特色"。那自然的改进是：**让伪标签来自"支持集算出来的东西"，这样它就有任务特色了。**

两个例子：
* **原型（prototype）**：把每一类支持集样本的特征取平均，得到该类的"代表点"。然后"谁离这个代表点近就判给谁"。因为支持集是这一局特有的，所以这个老师**有任务特色**。
* **标签传播**：在图上让标签从有标签点扩散出去，也是用支持集算的，**也有任务特色**。

#### 数据：结果反而更糟

| 做法 | 主干准确率变化 |
|---|---|
| 原型蒸馏进内层 | 75.86 → **54.34**（随机是 20%） |
| LP 蒸馏进内层 | 75.86 → **42.23** |

#### 【白话】为什么会塌缩

因为这两个老师的"最优解"都是**没意义的退化解**：

* **原型蒸馏的最优解**：把所有无标签点都拉到它们各自的原型上 → 最终**所有同类点塌成一个点**，特征失去区分度。
* **熵最小化的最优解**：把所有点都推向同一类 → 预测全变成同一个答案。

**而外层只监督查询集的损失 $L_Q$，它和 $L_U$ 的最优解不一致。** 两个目标互相拉扯，内层 SSL 项又权重不小，于是表示被拉垮。

#### 论文原文支持（Ren et al., ICLR 2018）——他们用类似的方法，但是能行

> "we chose to **extend Prototypical Networks** in this work for its simplicity and efficiency."

（我们选择扩展原型网络，因为它简单高效。）

—— 注意这句的言下之意：他们**选择了 prototype 网络这类 metric-based 方法，而没有选择 MAML 这类梯度型方法**。

> "We could perform several iterations of refinement... However... **found results to not improve beyond a single refinement step**."

（我们试过多次迭代精修……**发现超过一步就没有提升了**。）

#### 【白话】为什么他们能行，我们不行？

因为他们的精修是 metric-based 流水线里的**一步闭式解**：

* **闭式解** = 有现成公式直接算出来，不用迭代；
* **不参与二阶求导** = 元梯度不用穿过它，不会和目标互相拉扯。

**而我们做的是"把半监督项塞进梯度内循环"** —— 它必须参与二阶求导，于是必然要和外层目标争夺梯度。

**所以这条原文恰好说明**：想让半监督在内层有效，需要同时满足三条——
1. 是**闭式或一步**算子（不是需要上万步的动力学）；
2. 输出**由支持集显式参数化**（任务特异）；
3. 目标与元目标**方向一致**（不产生退化解）。

**而这在 MAML 式梯度内循环里很难同时满足。**

---

### 机理小结

$$\text{内层 SSL 失效} = \underbrace{\text{M1 预算不够}}_{\text{来不及生效}} + \underbrace{\text{M3 任务无关占主导}}_{\text{退化成对 }\theta_0\text{ 的正则}} + \underbrace{\text{M4 目标退化}}_{\text{一旦生效方向就错}} + \underbrace{\text{M2 阈值掐断}}_{\text{梯度为空}}$$

**【白话版总结】**：

* **M1**：这个机制需要跑很久才见效，内层只跑 3–5 步，根本来不及。
* **M2**：FixMatch 的筛选开关（阈值）在这么短的适应里几乎全是关着的，所以那部分损失等于 0。
* **M3**：内层只轻轻动了一下参数，所以"无标签数据的预测"几乎就是"通用起点"的预测，没有任务特色 → 这项损失主要在管**共用的起点**，而不是**这一局的具体解法**。
* **M4**：如果想让它变得有任务特色（用原型、用标签传播），这些老师的"最优解"本身是塌缩的，会把模型带坏。

---

## 第 7 步 · 正面验证：换个位置确实有效（不是"半监督没用"）

### 逻辑

如果结论是"半监督没用"，那换位置也不该有效。
**换位置有效，才证明这是"位置"的问题。**

### 数据

| 主干 | 只做监督适应 | **适应后 + 标签传播** | 增益 |
|---|---|---|---|
| 随机初始化 | 31.19 | 31.06 | **−0.13** |
| 联合预训练 | 25.37 | 25.23 | **−0.14** |
| **MAML 二阶** | **75.86** | **82.64** | **+6.78** |
| FOMAML | 78.94 | 81.30 | +2.36 |

### 【白话】这张表同时说明两件事

**第一件：适应之后做半监督确实有效（+6.78）。**
同样的任务、同样的标签预算，只是在"适应完之后"多用了一下无标签数据，准确率从 75.86 涨到 82.64。

**第二件（更重要）：第三段的增益 100% 来自第一段学到的表示。**
看前两行——**起点不好的时候（随机初始化、普通预训练），标签传播的增益是 0（甚至 −0.13）**。

**【白话】** 标签传播本身不"生产"信息，它只是把**已有的、好的表示**里隐含的结构"读出来"。表示里没有结构（因为没学好），它读出来的就是噪声。

**所以：元训练负责把任务结构解出来，非参数精炼负责利用无标签几何；两者不可互相替代。**

### 【白话】公平性说明

有人会质疑："标签传播用了查询集的输入（直推式），而纯监督没用，这不公平。"

**我们的回应**：所有内循环 SSL 变体（`sup_ent`/`sup_lp`/`ssl_ent`/`ssl_lp`）**同样能看到查询集的输入**（它们也都在查询输入上算无标签损失）。在这个**同等信息访问权**下，最高的内循环变体也只有 79.44% < 82.64%。

**所以"放在适应之后更好"这个结论，不是因为多看了数据。**

### 真实数据上的验证（USGS 37 站 × 705 天，次日 pH 回归）

| 设定 | 纯监督 MSE | **Pseudo-Label MSE** | 配对 ΔMSE | 相对 |
|---|---|---|---|---|
| 随机划分 K=10 | 0.378 | **0.299** | −0.0792 ± 0.0165 | **−20.9%** |
| 随机划分 K=30 | 0.387 | **0.294** | −0.0935 ± 0.0459 | **−24.1%** |
| 空间划分 K=30 | 0.283 | **0.250** | −0.0333 ± 0.0066 | **−11.8%** |

**【白话】** MSE 是"预测误差的平方平均"，**越低越好**。这张表说的是：把 Pseudo-Label 放在适应之后，真实数据上的预测误差降低了 **11.8% 到 24.1%**，而且这个降低在三种不同划分下都成立。

**这证明"半监督非常有用"，只是必须放在适应之后。**

## 第 8 步 · 排除"是不是你调参不行"

**逻辑**：以上所有结论都会被认为是"没调好"。所以必须给一个**无法用调参解释**的证据。

### 做法

在**源域任务**（留出的 6 个源站点，完全不碰目标域的标签）上对每个方法做权重网格搜索：

| 方法 | λ=0 | λ=0.005 | λ=0.05 | λ=0.1 | λ=0.2 | λ=1.0 | **选出的最优 λ** |
|---|---|---|---|---|---|---|---|
| **Pseudo-Label** | 0.2531 | — | 0.2263 | — | 0.2004 | **0.1705** | **1.0** |
| FixMatch 回归形式 | 0.2531 | 0.3295 | — | 0.3793 | — | — | **0.0（不用）** |
| VAT 回归形式 | 0.2531 | 0.2873 | — | 0.4393 | — | — | **0.0（不用）** |

（数值为源域验证 MSE，越低越好；λ=0 就是"完全不使用半监督项"。）

### 【白话】这张表在说什么

* **λ 是半监督项的权重**：λ=0 就退化成纯监督。
* 我们对每个方法都**把所有 λ 都试了一遍**，看哪个最好。
* **Pseudo-Label**：λ 越大越好（0.2531 → 0.2263 → 0.2004 → 0.1705），说明这项确实有用，选 λ=1.0。
* **FixMatch / VAT**：**所有非零 λ 都比 λ=0 差**，所以"最优选择"就是 **λ=0（干脆别用）**。

**这排除了"你只是没调好"的可能**——**是网格搜索自己得出了"不要用它"的结论。**

### 另外两个排除手段

1. **元梯度实现正确性**：用有限差分（数值求导）校验解析梯度，二阶元梯度相对误差 **1.8×10⁻⁵**。（代码：`tests/test_maml_grad.py`）
2. **VAT 方向的秩定理**：解析式与数值 Hessian 相对误差 **~1e−12**，特征向量与梯度 $|\cos|=\mathbf{1.000000}$。（代码：`verify_vat_regression.py`）
   **这是数学结论，不是调参。**

## 最终结论与整条逻辑链

$$\boxed{\text{半监督信号不应放进 MAML 的 inner loop，而应放在适应之后（三段式的第三段）}}$$

### 推导链回顾

| 步 | 内容 | 依据 |
|---|---|---|
| 1 | MAML 把损失函数当成可替换的"插件"，且全文没试过半监督 | 论文原文 |
| 2 | 写成可否证的假设 H₀ + 两个可观测预言 A、B | 逻辑 |
| 3 | **预言 A 被否证**：9 个「主干×SSL」组合全部为负 | 实验一主表 |
| 4 | **预言 B 被否证**：没有"先升后降"，只有"死区 → 断崖 −23 点" | $(\alpha,m)$ 扫描 |
| 5 | 机理：M1 预算不够 + M2 阈值掐断 + **M3 任务特异性只有 $O(\alpha m)$** + M4 退化解 | 论文原文 + 实验 |
| 6 | **正面验证**：同一方法换到外层 +3.58、换到适应后 +6.78；真实数据 Pseudo-Label −11.8%~−24.1% | 实验 |
| 7 | 排除调参：源域网格搜索把 FixMatch/VAT 的权重选成 0；元梯度与秩定理经数值校验 | 实验 + 数学 |

### 【白话】整条链一句话讲完

> ① 论文留了个口子让我可以往内层塞半监督项；
> ② 我把它写成两个能被打脸的预言；
> ③ 试了三种方法，**全部变差**；
> ④ 把力度调大，**不是变好而是更差** → 说明不是"力气不够"，是"方向错了"；
> ⑤ 找原因：**内层走得太少，所以伪标签其实来自共享起点，没有任务特色，这项损失等于在管"通用起点"而不是"这一局"**；
> ⑥ **如果把同一个东西换到别的位置就有效**（外层 +3.58、适应后 +6.78）→ 证明是位置问题，不是方法问题；
> ⑦ 而且**自动调参也得出同样结论**（FixMatch/VAT 的最优权重是 0），所以不是我没调好。

### 整条链最关键的一步

**第 6 步（正面验证）。**

如果只能给出"内层不行"，那只是一个**负面结果**，很容易被认为"是你没做好"。
**能证明"换个位置就有效"，才能把结论从"半监督没用"精确地收窄到"半监督的位置错了"**——这也是这个结论能被写进论文的原因。
