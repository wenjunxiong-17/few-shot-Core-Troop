# 半监督方法能否放进 MAML 的 inner loop？
### —— 机制分析、受控实验证据，与面向该问题的数据集设计建议

> 本文档基于三篇论文的精读（MAML / FixMatch / Zhu 2008 SSL Survey）、一次文献检索、以及在本工作区复现并运行的 NumPy 元学习实验（合成小样本分类 + 水质数据站点少样本适应）。

## 0. 一页结论

### Q1：能否把半监督方法放进 MAML 的 inner loop 来提升性能？

**形式上可以，实质上有系统性障碍；在本工作的受控实验中一致有害。**

* 形式上：MAML 唯一的要求是"内层损失对 θ 足够光滑"（原文：*the loss function is smooth enough in θ*），所以
  $$\theta'_i=\theta-\alpha\nabla_\theta\big[L_S(\theta;D)+\lambda L_U(\theta;D_U)\big]$$
  在框架层面完全合法，FixMatch 的伪标签项、熵最小化、一致性正则、原型/软 k-means 都属于这一类。
* 实质上，有一系列系统性障碍让它难以奏效（§2，M1–M9）：时间尺度错配、阈值/argmax 的零梯度面、任务特异性仅 $O(\alpha m)$、元目标退化、二阶代价与方差、直推式元过拟合。
* 实验（§3，合成 5-way 1-shot，8 维输入其中 6 维纯噪声，400 个测试任务）：

  | 同一主干下的内循环 SSL | 准确率变化 |
  |---|---|
  | MAML 二阶 + 熵最小化 | 75.86 → **63.05**（−12.81） |
  | MAML 二阶 + 原型蒸馏 | 75.86 → **71.64**（−4.22） |
  | MAML 二阶 + LP 蒸馏 | 75.86 → **65.96**（−9.90） |
  | FOMAML + 熵最小化 | 78.94 → **75.82**（−3.12） |
  | FOMAML + LP 蒸馏 | 78.94 → **74.43**（−4.51） |

  在**同等无标签信息访问权**（都是直推式，都能看到 query 的输入）下，所有内循环 SSL 变体都 ≤ 79.44%，而"先适应再传播"达到 **82.64%**。
* 一个例外：把 SSL 项放在**元训练的目标里**（作为元正则项）而不是放在适应时，能把初始化本身变好（熵最小化：75.86 → 79.44）。

### Q2：三段式"预训练/元训练 → 极少数标签适应（钉锚点）→ 自训练/标签传播"能否胜过标准 MAML？

**能，而且这是本工作中唯一稳定奏效的路线；但第三段必须是"非参数直推精炼"，不是把伪标签再灌回参数。**

* 合成实验：

  | 主干 | 只做监督适应（标准 MAML） | + 适应后标签传播 | 增益 |
  |---|---|---|---|
  | 随机初始化 | 31.19 | 31.06 | **−0.13** |
  | 联合预训练（普通监督） | 25.37 | 25.23 | **−0.14** |
  | **MAML 二阶** | **75.86** | **82.64** | **+6.78** |
  | FOMAML | 78.94 | 81.30 | +2.36 |

  → **第三段的增益 100% 来自第一段学到的表示**：起点不好时，标签传播一点也帮不上（随机初始化/普通预训练两行增益为 0）。
* 回归任务（水质数据，新站点部署场景，$K=10$ 个锚点）：MAML 元训练 **0.400**，优于逐站点岭回归 **0.487**（好 18%）；第三段在**随机站点划分**下无增益（0.407），但在**跨区域划分**（coastal → Atlanta）下把 0.459 降到 **0.406（相对 −11.5%）**。→ **第三段的价值 ≈ 无标签数据相对于元训练先验的"新增信息量"**：同分布时趋近 0，有域偏移时显著为正。
* 反直觉但重要的发现：**把第三段的非参数结果"再参数化"（用伪标签重训整个网络）会退化**；自训练轮数 >1、学习率 >1e-3 时会漂移（这正是 Zhu 2008 所说的 *a classification mistake can reinforce itself*，即今天的 confirmation bias）。
* 因此三段式的正确表述是：

  $$\theta_0=\mathrm{MetaTrain}(p(\mathcal T))\;\longrightarrow\;\theta_s=\mathrm{Anchor}(\theta_0,\;K\ \text{个标签})\;\longrightarrow\;\hat y=\mathrm{Refine}_{\text{非参数}}(\theta_s,\;U)$$

  其中第三段的强度应当由 $U$ 的信息量而非固定超参决定。

## 1. 三篇论文的接口提炼：能塞什么，代价是什么

### 1.1 MAML 的接口（Finn, Abbeel, Levine, ICML 2017）

Algorithm 2（few-shot 监督）逐行：

```
5: Sample K datapoints D = {x^(j), y^(j)} from T_i
6: Evaluate ∇_θ L_{T_i}(f_θ) using D and L_{T_i} in Eq (2) or (3)
7: θ'_i = θ − α ∇_θ L_{T_i}(f_θ)
8: Sample datapoints D'_i = {x^(j), y^(j)} from T_i for the meta-update
10: θ ← θ − β ∇_θ Σ_{T_i} L_{T_i}(f_{θ'_i})
```

**可注入点（按行号）**

| 注入点 | 形式 | 含义与风险 |
|---|---|---|
| **I1 · 第 6–7 行（内层损失）** | $\theta'_i=\theta-\alpha\nabla_\theta[L_S+\lambda L_U]$ | 唯一真正改变"适应过程"的位置。要求 $L_U$ 对 θ 可微（MAML 原文只假设损失足够光滑）。若 $D_U$ 包含 query 的**输入**，则适应算子变成直推式，元训练阶段必须同构直推，否则训练/测试适应算子不一致 |
| **I2 · 第 5 行（采样）** | 除 K 个 $(x,y)$ 外再采 M 个无标签 $x\sim q_i$ | MAML 原文的形式化里 $x$ 本就由任务自己的 $q_i$ 产生（*The task T_i generates K i.i.d. observations x from q_i*），只有 $y$ 是任务相关的。这是**不改标签预算而增加信息的唯一通道** |
| **I3 · 第 8–10 行（元更新）** | 给元损失加 $\lambda' L_U(f_{\theta'_i};D'_U)$ | 元目标的语义就从"任务损失"变成混合代理；$D'_i$ 在原文里定义为带标签集合，替换成无标签会破坏 Algorithm 2 第 10 行。**建议：SSL 只进内层，外层保持有标签任务损失** |
| **I4 · Require 行** | 新增 $\lambda$（可元学习） | 原文提供了先例：*The step size α may be fixed as a hyperparameter or meta-learned* |
| **I5 · RL 分支** | — | 结构性障碍：*each additional gradient step during the adaptation requires new samples from the current policy*（on-policy，采样不可微） |

**成本接口**：加入 $L_U$ 后
$$\frac{d\theta'_i}{d\theta}=I-\alpha\nabla^2_\theta(L_S+\lambda L_U)$$
Hessian 项多出 $\lambda\nabla^2 L_U$。若用 FOMAML（论文实测在 MiniImagenet 上与全二阶差 ≤0.63 个点、省约 33% 时间），该项被整体丢弃，内层加 SSL **几乎不增加反传成本**——这是该方向最经济的技术路线。

### 1.2 FixMatch 的接口（Sohn et al., NeurIPS 2020）

$$l_s=\frac1B\sum_b H\big(p_b,\;p_m(y|\alpha(x_b))\big),\qquad
q_b=p_m(y|\alpha(u_b)),\qquad \hat q_b=\arg\max q_b$$
$$l_u=\frac{1}{\mu B}\sum_{b=1}^{\mu B}\mathbb 1\big(\max(q_b)\ge\tau\big)\,H\big(\hat q_b,\;p_m(y|A(u_b))\big)$$

主实验超参：$\tau=0.95$、$\lambda_u=1$、$\mu=7$、$B=64$（→ 每步 448 个无标签样本）、SGD+Nesterov $\eta=0.03$、余弦调度 $\eta\cos(7\pi k/16K)$、$K=2^{20}\approx1.05\times10^6$ 步。

**与 1–5 步可微内循环的冲突（定量）**

| 论文的实际要求 | 数值 | 与 MAML 内循环的冲突 |
|---|---|---|
| 总训练步数 K | ≈1.05×10⁶ | 内循环 5 步 = 全轨迹的 4.8×10⁻⁶ |
| 每步无标签样本 $\mu B$ | 448 | 任务级 batch 通常 O(10)，阈值统计量方差爆炸 |
| 单次运行消耗无标签样本 | ≈4.7×10⁸ | 内循环 5 步 × 160 ≈ 800，差 ~6 个数量级 |
| τ=0.95 的保留率 | 训练**末期**才 98.13%（τ=0.99 时 92.14%） | 论文 §2.2 明说 *max(q_b) is typically less than τ early in training* → 在 meta-init 上跑 5 步，**mask 期望 ≈ 0，无监督梯度为空** |
| 强增强的收益 | 弱增强代替强增强 → 峰值 45% 后崩到 12% | 长期累积正则，5 步内无从体现 |
| mask 与 argmax | $\arg\max$、$\mathbb 1(\max q\ge\tau)$ 对 θ 几乎处处导数为 0 | 任何"元学习 τ / 元学习何时采信伪标签"的路径**拿不到梯度** |

**能活下来的部分**：把伪标签与 mask 都 detach 成常数后的
$$l_u^{\text{inner}}(\theta)=\frac{1}{|B_u|}\sum_b m_b\,H\big(\mathrm{detach}(\mathrm{onehot}(\arg\max q_b)),\;p_\theta(A(u_b))\big)$$
对 θ 可微（梯度只走强增强分支）；弱/强双增强结构、有标签样本复用进无标签池（脚注 2）、软置信权重 $w_b=\sigma((\max q_b-\tau_t)/s)$ 都可保留。

**活不下来的部分**：τ=0.95 的"免费课程"（§2.2 明确把它当作省略 $\lambda_u$ 退火的理由）、硬阈值选择的元梯度、强增强的累积正则、10⁵–10⁶ 步的动力学。

### 1.3 Zhu (2008) SSL Survey 的家族与可微性

| 家族 | 核心目标 | 直推/归纳 | 对"内循环"的可微性 |
|---|---|---|---|
| 生成式 EM（§2） | $\max_\theta\sum_L\log p_\theta(x,y)+\lambda\sum_U\log\sum_y p_\theta(x,y)$ | 归纳 | 硬 EM 的 E 步 argmax 不可微；软后验（responsibility）松弛后可微 |
| 自训练（§3） | 无统一目标（wrapper） | 取决于基学习器 | top-k 选择 + 硬标签不可微；软伪标签/置信度加权可微 |
| 协同训练（§4） | 两视图一致性 | 归纳 | 同自训练；co-EM 是标准松弛 |
| TSVM/S3VM（§5.1） | $\sum_L(1-yf)_++\lambda_1\|h\|^2+\lambda_2\sum_U(1-\lvert f\rvert)_+$ | 归纳 | 非凸、NP-hard；需平滑化/退火/CCCP |
| **熵最小化（§5.4）** | $\min-\sum_L\log p(y\lvert x)+\lambda\sum_U H(p(y\lvert x))$ | 归纳 | **原生完全可微**（最易塞进内循环） |
| **图方法/标签传播（§6.1.3）** | $\infty\sum_L(f_i-y_i)^2+\tfrac12\sum_{ij}w_{ij}(f_i-f_j)^2$ | **直推**（§6.4 明说 *cannot easily extend to new test points outside of L∪U*） | **闭式解 + 非参数 + 直推**，不能平凡反传；须软钳制 / 迭代展开 / 核参数化 / stop-gradient 四选一 |
| Manifold 正则 / 半监督核（§6.1.6） | $\frac1l\sum V+\gamma_A\|f\|_K^2+\gamma_I\|f\|_I^2$ | **归纳** | 可微（图信息被参数化） |
| 类别比例正则（§7） | $-\sum_L\log p+\lambda KL(\tilde p\|\tilde p_\theta)$ | 归纳 | 可微，但**1–5/类下比例估计极不可靠**，不加约束会把所有点判成一类 |
| 表示学习（§8） | 两视图辅助问题 + SVD | 归纳 | 对应三段式的**第一段（预训练）** |

**Survey 的两条硬警告（对本文选题直接相关）**
1. *No free lunch. Bad matching of problem structure with model assumption can lead to degradation.* —— 并点名**权重由成对距离决定的图方法**。也就是说：**若协变量空间里没有与标签一致的簇结构，标签传播不是"没有增益"，而是"有害"**。
2. §6.5 明说 consistency 仍是开放问题；未归一化 Laplacian 的特征向量收敛性存在反例。

**一处需要澄清的差异**：TIM 在**普通预训练**特征上做转导精炼就能拿到 2–5 个点，而本工作实验一里"联合预训练 + 标签传播"的增益为 **0**。原因不是矛盾，而是任务族的差别：miniImageNet 的基座表示已经能把新类聚开（固定标签空间），而本工作任务族每个任务有**任务特异的 warp 与相位**，共享预训练特征无法解决，必须先靠**元训练 + 支持集适应**把任务结构解出来。所以第三段的前提条件应当写成：

> **第三段有效 ⟺ 适应后的表示在"该任务的无标签点上"已经形成与标签一致的簇/流形结构。**

这也是 §5.2 中 R2 的另一种表述。

## 2. 为什么"把 SSL 塞进 inner loop"在原理上受限：八条机理与两条工程判据

记内层步长 $\alpha$、步数 $m\in\{1,\dots,5\}$、支持集 $D_S$、无标签池 $D_U$、查询集 $D_Q$。

### M1 · 时间尺度错配（成本层面）
MAML 的内循环是 $m$ 步、每步用同一个 K 点小批；FixMatch 需要 $10^6$ 步、每步 448 个无标签样本。内循环能承载的无标签样本量比 FixMatch 单次运行少约 **6 个数量级**（§1.2 表）。**自训练/一致性正则的收益来自长期动力学，而不是单步损失函数的形式**。这不是"实现问题"，是预算问题。

### M2 · 阈值与 argmax 的零梯度面（信息层面）
FixMatch 的两个核心机制——$\arg\max q_b$ 与 $\mathbb 1(\max q_b\ge\tau)$——作为 θ 的函数是**分片常数**，几乎处处导数为 0。于是：
* 元梯度看不到"该采信哪些样本"；
* $\tau$ 若作为元参数，梯度几乎处处为 0（需 REINFORCE 或软松弛）；
* 更要命的是**课程效应**：FixMatch §2.2 明说训练早期 $\max(q_b)<\tau$。在一个只做了 $m\le5$ 步的 $\theta'$ 上，mask 的期望 ≈ 0，**无监督梯度为空**。要恢复信号必须把 τ 降到 0.25–0.5，而那正是论文 τ 扫描里掉点（4.84 → 5.87/6.40）与杂质率升高（3.47% → 5.40%/6.39%）的区间。

### M3 · 任务特异性是 $O(\alpha m)$ 的高阶小量（机理层面，本文的核心论点）
内层一步：$\theta'=\theta_0-\alpha\nabla L_S(\theta_0)$，而伪标签由 $\theta'$ 产生，于是
$$\theta'=\theta_0+O(\alpha m).$$
由于 $\|\alpha\nabla L_S\|$ 很小（MAML 的 α 常取 0.01–0.4，而 $L_S$ 在少量 K 点上的梯度并不大），**伪标签几乎就是 $\theta_0$ 的预测**；而 $\theta_0$ 是**跨任务共享**的。因此内层 SSL 项 $L_U(\theta';D_U)$ 对 θ 的依赖中，**任务无关的那一部分占主导**，任务相关部分只有 $O(\alpha m)$。

**这个预言被实验 1b 精确证实**（§3.4）：当 $\alpha m\lesssim0.1$ 时，内循环 SSL 的效果与基线之差不超过 ±1 个点（几乎没有作用）；只有当 $\alpha m$ 变大时它才"生效"。

**但"生效"的方向是坏的**：实验 1b 显示，$\alpha m$ 增大时掉点从 −0.1 迅速扩大到 **−23 个点**。也就是说，M3 解释了"为什么小步长下它没用"，M4 解释了"为什么大步长下它有害"。两者合起来才是完整图景。

**要让内层 SSL 真正有益，老师必须由支持集显式参数化**（如原型/软 k-means：老师 = 支持集特征的类均值）。但这又引出 M4。

### M4 · 元目标偏置与退化解（目标层面）
若内层 SSL 的老师由支持集参数化（原型、LP），那么 $L_U$ 的最优解往往是一个**退化解**（把未标注点全部拉向各自原型 → 特征塌缩；或熵最小化把所有点推向同一类）。而外层只监督 $L_Q$，它与 $L_U$ 的最优解不一致。在我们的实验中，这两个都塌了：
* 原型蒸馏进内层：主干准确率 75.86 → **54.34**（随机水平为 20%，表示被严重破坏）；
* LP 蒸馏进内层：75.86 → **42.23**。

Ren et al. 2018 之所以能用 soft k-means，恰恰因为它**不是梯度内循环**：它是 metric-based 流水线里对**原型估计**的一步闭式精修，由支持集与无标签点共同决定，不参与二阶求导。也正因此，作者观察到"迭代多于一步就没有增益"——因为那一步已经是闭式解附近。

### M5 · 二阶代价与方差（优化层面）
$d\theta'/d\theta=I-\alpha\nabla^2(L_S+\lambda L_U)$。加入 $L_U$ 后 Hessian 项多出 $\lambda\nabla^2L_U$；在 K 很小、无标签 batch 也很小时（任务级 batch 仅 O(10)），HVP 的方差显著上升。用 FOMAML 可以绕开，但 FOMAML 在 MiniImagenet 上与全二阶差 ≤0.63 个点这一事实也说明**二阶项本身贡献有限**——把预算投在二阶上不如投在别处。

### M6 · 反过来的情形：什么时候"内循环 SSL"是对的
把上面几条合起来，可以给出一个**判据**：

> 内循环 SSL 只有在同时满足以下三条时才有望有效——
> (i) 它是一个**闭式或一步**算子（不是需要上万步的动力学）；
> (ii) 它的输出**由支持集显式参数化**（因而任务特异，而非退化为对 θ₀ 的正则）；
> (iii) 它的目标与元目标**方向一致**（不产生塌缩/退化解）。
>
> 现实中最接近这三条的是 **soft k-means / 原型精修**（Ren et al. 2018），且它天然属于 **metric-based（ProtoNet 式）** 流水线，而不是 MAML 式梯度内循环。这与我们的实验一致：MAML 式内循环里的原型蒸馏会塌缩。

### M7（补充）· 直推式元学习的过拟合
若 $D_U$ 包含 query 的**输入**（直推），内循环就"看到了"评估点的输入分布，元学习会学到"如何利用这批特定输入"，从而对元训练任务过拟合。Ren et al. 2018 的显式设计决策（*split out a separate unlabeled set that is different from the query set*）正是为了避免这一点。若采用直推，必须保证元训练阶段同构直推，且**在报告中明确声明**——MAML 原文对直推/归纳没有任何说明，这是复现口径的最大缺口。

### M8 · 直接检验（实验 1b）

上述机理中 **M3 给出一个可检验的定量预言**：内循环 SSL 的任务特异分量是 $O(\alpha m)$，因此
* 当 $\alpha m$ 很小时，内循环 SSL 项几乎不随任务变化 → 退化为对 $\theta_0$ 的正则，效果应接近 0；
* 当 $\alpha m$ 增大时，老师开始携带任务信息 →（**先验预测**）危害应先减轻，因为此时它更像"任务特异的自训练"；
* 但 $\alpha m$ 继续增大时，$\theta'$ 已能单独拟合支持集，此时退化解（M4）与过拟合可能重新占优。

实跑结果只证实了第一、三条，**第二条被证伪且方向相反**：任务特异性一旦生效，掉点反而从 −0.1 迅速扩大到 −23 个点（§3.4）。这个"证伪"本身是有信息量的——它说明问题不在"信号太弱"，而在"信号生效时指向的方向是错的"（M4）。

对同一个 MAML 主干（$\alpha=0.4$、1 步训练），在元测试时扫描 $(\alpha,m)\in\{0.05,0.1,0.2,0.4,0.8\}\times\{1,3,8\}$，并在三种内循环目标下评测：纯支持集 CE、加入无标签熵最小化、加入"冻结初始化的教师"一致性项（后者**按构造是任务无关的**，因为在 $\theta=\theta_0$ 处其损失与梯度都恰为 0）。完整结果见 `results/exp1b_alpha_sweep.json` 与 §3.4。

### M9 · 如果一定要把 SSL 放进内循环，怎么做才可能不亏（工程建议，均为本工作的分析/未全部验证）
1. **把 SSL 项放在元训练目标里，而不是适应时**。本工作实测：熵最小化作为元正则 +3.58 个点；作为适应项 −12.81 个点。这是投入产出比最高的一步。
2. **若必须在适应期用，把老师改成"冻结的元初始化的预测"**（consistency toward $\theta_0$）。它在 $\theta_0$ 处损失与梯度都为 0，因此不会在第一推动手，是最温和的注入形式——代价是它按构造不含任务信息。
3. **不要用固定阈值 0.95**。任务级 batch 通常 < 100，早期保留率过低会导致 mask 全 0。改用**任务内分位数阈值**（保留每个任务置信度前 $q$ 分位），$q$ 是任务级标量，比全局 $\tau$ 更适合元学习。
4. **软化 mask**：$w_b=\sigma\big((\max q_b-\tau_t)/s\big)$，使 $\tau_t$ 的元梯度非零（硬 $\mathbb 1(\cdot)$ 几乎处处为 0）。
5. **用 FOMAML**：让内循环加 SSL 的成本几乎不增加（二阶项的 HVP 被整体丢弃）。
6. **限定步数预算**：内循环 SSL 只在 $m$ 与 $\alpha$ **都小**时是"温和的正则"，$m\ge3$、$\alpha\ge0.4$ 时会迅速变成损害项（实验 1b）。
7. **若要用"任务特异性老师"，请转到 metric-based 流水线**（ProtoNet + soft k-means，Ren et al. 2018），因为那里精修是闭式一步，不参与二阶求导，也就不会与元目标争夺梯度（M6）。

## 3. 受控实验：合成小样本分类（决定性证据）

### 3.1 任务设计（为什么必须这样设计才公平）

朴素的"簇状高斯 + 少量标签"任务**不能**回答这个问题，因为**在原始输入空间里标签传播就已经做得很好**，元学习没有存在价值，结论会退化成"SSL 都能用"。本实验用两条设计消除这个退化：

1. **噪声维度**：输入维度 8，其中只有前 2 维承载类别结构，其余 6 维是纯噪声（$N(0,1)$，而信号尺度 $\sigma=0.35$）。这样：
   * **不学表示的标签传播 = 随机**（实测 `raw_lp` = 31.33%，随机初始化 + LP = 31.06%，普通联合预训练 + LP = 25.23%）；
   * **只有学好表示之后，标签传播才有意义**。
2. **任务特异性**：类均值圆环的相位 $\psi$ 每个任务随机；再叠加一个各向异性线性变换 $A$（旋转 + 对数均匀的奇异值 $\exp(\pm0.4)$）。所以"半径/角度"这条规则每个任务都不同，必须靠支持集推断。

配置：5-way **1-shot**（每类 1 个标签，共 5 个）、query/unlabeled 75 点、元训练 2500 次迭代 × 16 任务、元测试 **400 个任务**；网络 8→40→40→5（ReLU）；MAML $\alpha=0.4$、训练 1 步内循环、评测 3 步；二阶用有限差分 HVP（已通过有限差分校验，相对误差 1.8×10⁻⁵）。
评估一律**直推式**：所有方法都能使用 query 的输入，但只有支持集的标签可用。

### 3.3 三条结论

**结论 1：元学习本身是有效的，而且是必需的。**
MAML 二阶 75.86 / FOMAML 78.94，而联合预训练仅 25.37、随机初始化 31.19、原始输入上的标签传播 31.33。这说明在本任务族里，**表示必须靠元学习获得**，任何"跳过元训练直接上 SSL"的做法都无效。

**结论 2（回答 Q1）：把 SSL 放进 inner loop 一致有害，且塌缩是机制性的。**
同一主干下，内循环加入任何 SSL 项都掉点：

| 主干 | 无内循环 SSL | +熵最小化 | +原型蒸馏 | +LP 蒸馏 |
|---|---|---|---|---|
| MAML 二阶 | 75.86 | −12.81 | −4.22 | −9.90 |
| FOMAML | 78.94 | −3.12 | −3.17 | −4.51 |
| MAML⁺熵最小化 | 79.44 | −3.48 | −2.97 | −4.19 |

更严重的是**把 SSL 项作为元训练目标**时：
* 熵最小化（可微、无退化解）→ 主干 79.44（**比纯 MAML 高 3.58**）；
* 原型蒸馏 → 主干 **54.34**（塌缩）；
* LP 蒸馏 → 主干 **42.23**（塌缩）。

这与 M3/M4 的预测完全一致：**可微、无退化解的 SSL 项主要在充当"对初始化的正则"（有效）；一旦它带有由支持集参数化的老师（任务特异但目标退化），就会与元目标争夺梯度并把表示毁掉。**

**结论 3（回答 Q2）：适应后的非参数精炼是唯一稳定的大增益，且完全依赖第一段。**
MAML 75.86 → +LP **82.64（+6.78）**；FOMAML 78.94 → 81.30（+2.36）；而随机初始化 31.19 → 31.06（−0.13）、联合预训练 25.37 → 25.23（−0.14）。
**在同样能看到 query 输入的条件下**（`sup_ent`/`sup_lp`/`ssl_ent`/`ssl_lp` 都是直推式内循环），最高的内循环 SSL 变体也只有 79.44 < 82.64。所以"SSL 放在适应之后"严格优于"SSL 放在适应之中"。
另外：**用伪标签重训参数（自训练）比直接用非参数解更差**（80.58 / 79.03 vs 82.64）——第三段保持非参数/直推形态最好。

**与文献的对照**：TIM（NeurIPS 2020）在**普通预训练**特征上做转导精炼可获 2–5 个点；本工作用**元学习适应后**的特征做同类精炼获 **+6.78**，方向一致、幅度更大。而"联合预训练 + 同一精炼"增益为 **0**——差额正好是"元训练 + 支持集适应"的贡献。这给出一个可检验的分工假说：**元训练负责把任务结构解出来，非参数精炼负责利用无标签几何；两者不能互相替代。**

### 3.4 机理的直接检验：$(\alpha,m)$ 扫描（实验 1b）

**读法**

1. **安全区是 $\alpha m\lesssim0.1\text{–}0.3$。** 在这个区间内，内循环 SSL 与基线之差 ≤1 个点——**不是"有点用"，而是"根本没生效"**。这精确证实了 M3。
2. **一旦进入 $\alpha m\gtrsim0.4$，掉点断崖式扩大**（−12 → −23 个点）。所以"把 SSL 的信号调强一点就有用"这条路是错的：信号变强只是让它更快地把 $\theta'$ 推向对 query 有害的解（M4）。
3. **"冻结教师"项在 $\theta=\theta_0$ 处损失与梯度都恰为 0**（表格中 m=1 全部为 0.00，是严格按照预言的），这说明它确实是纯任务无关的正则。而它在 $\alpha m$ 大时**比熵最小化更差**（最多 −31.30），因为它直接与支持集适应对抗。→ **"把 SSL 当作对初始化的纯正则"也不是出路。**
4. 基线的行为本身也很说明问题：α·m 太大（α=0.8、m=8）时纯 MAML 自己也从 80.55 掉到 61.82，说明内循环本来就工作在"轻微适应"的区间。**在一个只允许轻微移动的算子里塞一个需要大幅移动才能生效的机制，是结构性不匹配。**

**结论**：内循环 SSL 的失败不是"没调好超参"，而是 **M1（预算不匹配）+ M3（任务无关占主导）+ M4（目标退化）** 三者叠加的必然结果。

### 3.5 附加发现

1. **标签传播与参数化模型对锚点数的敏感度相反，因此二者互补。**
   * 合成任务（$K=1$/类）上 LP 已经能带来 **+6.78**；
   * 水质回归上 $K=10$ 时 LP 完全无用（0.773 vs MAML 0.400），$K=30$ 时仍差（0.683），只有在特征足够好、锚点足够多时才接近有效。
   → 自然的混合是"用参数化模型的预测作为 LP 的先验"（本工作实现了 `sup_then_lp_seeded`，在跨区域设定下 0.428 vs 直接适应 0.459）。
2. **自训练的超参窗口很窄，且"全网微调"比"仅头部微调"危险得多。** 在合成任务的同一主干上（150 步、1 轮）：

   | 学习率 | 仅头部 | 全网 |
   |---|---|---|
   | 3×10⁻⁴ | 81.5% | 81.5% |
   | 1×10⁻³ | 81.2% | 81.2% |
   | 3×10⁻³ | **81.7%** | 72.7% |
   | 1×10⁻² | 81.7% | **40.0%** |

   全网自训练在 3×10⁻³ 就开始漂移，1×10⁻² 时直接崩到随机水平；仅头部微调则几乎不受学习率影响。这正是 confirmation bias 的定量表现，也解释了 §3.3 结论 3 中"自训练不如直接用非参数解"。
3. **元训练时用 SSL 正则 vs 适应时用 SSL，是两个不同的位置，效果相反**：前者可以提升初始化（熵最小化 +3.58），后者一定掉点（−12.81）。任何"Semi-supervised MAML"的工作都必须明确自己把 SSL 放在哪一侧。

## 4. 水质数据上的三段式验证

### 4.1 数据诊断（决定了任务必须怎么定义）

`water_dataset.mat`：37 个监测站点 × 705 天 × 11 个水质指标，目标是 pH（README 写"次日预测"）。

诊断结论（详见 `reports/alignment_report.txt`）：

| 发现 | 数值 | 对建模的含义 |
|---|---|---|
| 目标离散化 | 训练集只有 **38 个不同取值**（步长 1/108），pH 值量化 | 目标近似有序离散；回归/分类两种建模都可行 |
| 强持续性 | 次日 pH = 当日 pH 的 MSE = 2.15×10⁻⁴，R²=0.752 | 单靠持续性就有很高 R²，容易高估方法 |
| 站点间水平差异巨大 | 站点均值范围 −1.44 ~ +2.30（全局标准化后），**站点内时间方差仅 0.42** | **主要任务是估计站点基线水平**，而不是预测快变分量 |
| 协变量→目标的映射接近线性 | 池化岭回归（25 站全量训练标签）= 0.357；逐站点岭回归（该站 422 个标签）= 0.265 | 表示学习的空间有限；元学习的价值在"少标签下估计站点水平" |
| **协变量预测的是站点水平** | 池化岭回归：**按支持集均值中心化 0.628 vs 不中心化 0.337** | **绝对不能做"按 K 个锚点中心化"**：那正好删掉协变量唯一能预测的东西（本工作踩过这个坑） |
| **标签传播对锚点数敏感** | 最终评测：$K=10$ 时 LP MSE = 0.773（远差于 MAML 0.400）；但诊断中两个示例站点在 $K=30$ 时 LP 达到 0.303 / 0.211 | LP 在 $K$ 小时被过度平滑（早期用带收缩的 label spreading 时预测标准差仅 0.02，而真值 0.52），$K$ 增大后才接近有效；**必须用硬钳制调和解，不能用带收缩的 label spreading**（后者在回归上是致命的偏置） |
| 图结构的选择很关键 | 协变量 kNN 图（$k=5$）远好于时间邻接图（$w=3/7/15$：0.42/0.75，因为测试期在时间链的远端） | 与 Survey "构图比选方法更重要" 一致 |

### 4.2 任务形式（可复用的场景定义）

**任务 = 一个监测站点**。这是水质场景里最自然的元任务划分，对应一个真实的部署情形：

> 在一个**新站点**部署传感器。传感器连续上报 11 个协变量（无标签，长期可用），但 pH 只能靠昂贵的实验室采样，因此**只有 K 天的 pH 标签**。要求在随后一年的预测期上给出 pH。

* 支持集（有标签）：从训练期随机抽 K 天；
* 无标签池：该站点**全部 705 天**的协变量（只有输入，没有标签）；
* 查询集：预测期（后 282 天）；
* 元训练/元测试：**按站点划分**（随机划分 25/12；另做空间划分：coastal 28 站 → 元训练，Atlanta 组 8+1 站 → 元测试）。

基学习器：11→40→40→1 的 ReLU 网络，MSE；$\alpha=0.02$、内循环 3 步（评测 8 步）、元学习率 $10^{-2}$（Adam）、元 batch 8、4000 次迭代。

### 4.4 结论

1. **第一段（给起点）在这份数据上是真实有效的，而且在标签越少时价值越大。**
   * $K=10$：MAML **0.400** vs 逐站点岭回归 0.487（**好 18%**），并显著优于联合预训练（1.052）与随机初始化（0.909）。
   * $K=30$：MAML 0.363 vs 逐站点岭回归 **0.313**（**反而更差**）。
   * 也就是说，**元学习的优势随锚点数增加而消失**——这符合"MAML 提供的是少样本先验"的预期，也说明在实际部署中应当**按标签预算选择方法**（$K\lesssim 15$ 用元学习，$K$ 更大时直接用逐站点回归就够了）。
2. **第二段（钉锚点）是必要的**：支持集均值 0.879 → MAML 0.400。
3. **第三段（放大无标签）的增益取决于"元训练与元测试任务之间是否存在分布偏移"**，这是本节最有价值的发现：

   | 设定 | 只做适应 | 最好的第三段 | 相对增益 |
   |---|---|---|---|
   | 合成小样本分类（§3） | 75.86% | 82.64% | **+6.78 点（+8.9%）** |
   | 水质 · $K=10$ · 随机站点划分 | 0.400 | 0.407 | −0.007（无） |
   | 水质 · $K=30$ · 随机站点划分 | 0.363 | 0.358 | +0.005（无） |
   | **水质 · $K=10$ · 空间划分（跨区域）** | **0.459** | **0.406** | **−0.053（相对 −11.5%）** |

   * 在**随机站点划分**下，元测试站点与元训练站点同分布，协变量→pH 的映射已经被元训练学好，无标签记录提供的信息（该站点的协变量分布）已被间接利用 → **第三段没有空间**。
   * 在**空间划分**（coastal → Atlanta）下存在真实的域偏移，元测试站点的协变量分布与元训练站点不同 → **无标签记录携带了元训练阶段看不到的信息**，第三段立刻带来 11.5% 的相对下降。
   * 这给出一个可操作的判据：**第三段的价值 $\approx$ 无标签数据相对于元训练先验的"新增信息量"**。同分布时它趋近于 0，有偏移或元训练任务不足时它显著为正。这也解释了为什么在 few-shot 图像分类上 SSL 精炼总是有效——那里的元测试类与元训练类是**不相交**的，天然存在偏移。
   * **注意**：空间划分的结果只来自一次划分、9 个测试站点，差值 0.053 与各自的边际标准误（0.05–0.08）同量级；由于所有方法共享同一批 episode，配对比较的功效更高，但仍应视为**提示性**结论，需要多划分重复确认。
4. **内循环 SSL 在这份数据上更糟**：作为元训练目标时，流形正则把主干毁成随机水平（$K=10$：0.945）或直接数值发散（$K=30$：$10^{42}$），LP 蒸馏同样（0.889 / 0.787）。这与合成实验（§3）方向一致，且更严重。
5. **FOMAML 在这份回归任务上不稳定**（默认学习率下发散，降到 3×10⁻³ 后 0.899 仍然远差于二阶 MAML 0.400）。这是一个值得记录的观察：在低维回归 + 11 个特征的设定下，忽略二阶项的近似代价比在图像分类上大得多。

> **这一节的意义**：水质数据足以验证"元训练 → 锚点适应"两段（并且确实有效，尤其在 $K=10$ 与跨区域时），并且**在跨区域场景下也验证了第三段**；但在同分布的随机划分下第三段没有空间。要系统研究第三段，需要能**控制"无标签数据携带多少任务参数信息"**的数据——这正是下一节的内容。

## 5. 数据集形式建议

### 5.1 现有数据的不足（针对本课题）

| 不足 | 后果 |
|---|---|
| 只有 **37 个任务**（站点） | 元学习需要成百上千个任务；37 个做元训练/元测试划分后每边只有几十个，方差大 |
| 目标**量化到 38 个水平**且强持续 | 天花板低、区分度差 |
| 协变量→目标**接近线性** | 表示学习的空间小，MAML 与"元学习式岭回归"难以区分 |
| **无标签数据携带的任务参数信息弱** | 随机站点划分下第三段没有增益；只有在跨区域划分下才显现（§4.4 第 3 点） |
| 没有显式的 support / unlabeled / query 三元切分，没有 distractor | 无法做 Ren et al. 式的鲁棒性实验 |
| 单目标、单模态 | 无法测试多视图/协同训练类方法 |

### 5.2 六条设计准则

> **R1 · 任务要足够多、且异质。** ≥ 500 个任务。任务 = 一个"传感器/站点/工况"，每个任务有自己的响应函数。
>
> **R2 · 任务特异参数必须能从"无标签数据"推断出来——这是让 SSL 有意义的唯一充分设计。** 具体可用的机制：
> * 任务特异的**线性增益/偏移**（无标签数据的分布范围揭示它）；
> * 任务特异的**有效子空间**（无标签点云的协方差揭示它，标签点太少无法揭示）；
> * 任务特异的**类别先验/比例**（无标签数据的聚类质量揭示它）；
> * 任务特异的**噪声水平**（决定该信任多少个无标签点）。
> 如果无标签数据不含任务参数信息，那么第三段必然只能带来边际增益——这正是当前水质数据的处境。
>
> **R3 · 显式三元切分 + distractor/OOD 控元。** 每个 episode 固定给出：support（有标签）、unlabeled pool（只有输入）、query（有标签、仅评测用）。并且**无标签池中的 OOD/干扰样本比例是一个可调的超参**（0%、10%、30%、50%），用来测第三段的鲁棒性（直接对应 Ren et al. 2018 的 distractor 设定）。
> **关键**：必须同时提供两个版本——`unlabeled ∩ query = ∅`（归纳/鲁棒版，Ren 的推荐）与 `unlabeled = query`（直推版）。**两种协议的结果绝不能混在一张表里比较。**
>
> **R4 · 标签预算与无标签预算都要做成曲线。** K ∈ {1,2,5,10,20,50} × M ∈ {0,50,500,5000}。这样才能把"锚点效应"和"放大效应"分离——本工作已经看到：**LP 在 K=10 时几乎无用，K=30 时才开始明显有效**，这只有在 K 曲线上才看得见。
>
> **R5 · 提供可信的合成孪生集（digital twin），并公布真值隐变量。** 真实数据只能给准确率；要证明"第三段确实恢复了任务参数"，需要**已知真值**。用与真实数据统计量匹配的生成模型（见下）产生成千上万个任务，同时输出每个任务的真实 (gain, offset, 子空间, 类别先验)，就可以做机制级分析（例如：LP 的增益是否正比于"子空间估计误差的下降"）。
>
> **R6（评测纪律）· 算力对齐与三个必做对照。** 报告每个方法消耗的**无标签前向/反传次数**（而不是"步数"），否则内循环 SSL 与后置 SSL 不可比。三个对照必须存在：
> * `random-init + 同一 SSL`：证明增益来自第一段（本工作：31.19 → 31.06，增益 0）；
> * `raw-input + 同一 SSL`：证明增益来自学到的表示（本工作：31.33）；
> * `oracle`（全量标签）：给出天花板。
> 同时必须报告"**只用 K 个标签、不用任何无标签**"的监督基线（本工作：逐站点岭回归）。

### 5.3 具体建议：在现有数据上做最小改造 + 建一个孪生集

**数据集 A：`Water-Meta-SSL`（在现有 37 站上改造，成本最低）**

* **任务扩容**：任务 = (站点 × 时间块)，例如 37 站 × 6 个 4 个月的时间块 ≈ 222 个任务；或任务 = (站点 × 目标指标)，若扩展到 pH/DO/电导率 3 个目标则 ≈ 111 个。
  *注意*：时间块切分必须按时间**前后**划分（用前块做支持、后块做查询），否则时间泄漏。
* **显式三元切分**：每个任务给出 `support_idx / unlabeled_idx / query_idx` 与 `distractor_idx`。
* **加"无标签携带信息"的机制**：把**其他站点的整段记录**混入无标签池（作为 distractor），并要求模型判断"哪些无标签点属于本站点"——这就是一个真实的、非人造的、含任务参数信息的半监督元学习问题（判断"属于本站点"等价于估计本站点的协变量分布）。
* **标签预算曲线**：K ∈ {1,2,5,10,20,50,100}，无标签池 M ∈ {0, 100, 500, 5000}。
* 派生分类版本：把 pH 离散化为 3–5 个区间（现有 38 个水平足够），得到 **N-way 分类**，从而可以直接使用 FixMatch/协同训练类方法。

**数据集 B：`SpatioTemporal-SSL-Meta`（校准到水质统计量的生成式孪生集，推荐重点做）**

生成模型（每个任务 $i$ 一个 episode）：

```
任务参数:  θ_i = (π_i ∈ Δ^{C-1},  A_i ∈ R^{d×k},  g_i ∈ R,  b_i ∈ R,  σ_i > 0)
            类别先验        任务特异子空间     增益      偏移      噪声
支撑集:    K 个样本,  (x, y) ~ p_i
无标签池:  M 个样本,  x ~ p_i        （可选混入 ρ 比例的 OOD/干扰样本）
查询集:    Q 个样本,  (x, y) ~ p_i  （Q ≫ K）
观测:      x = A_i z + ε,   y = g_i · f(z) + b_i + η
```

* $z$ 的维度 $k$ 可以取 2–5，$x$ 的维度 $d$ 取 20–200，**$A_i$ 随任务随机**——于是**只有用无标签点云的协方差才能恢复 $A_i$**，$K$ 个标签点无法恢复。这是 R2 的干净实现。
* 通过 $\rho$（OOD 比例）、$\sigma_i$（噪声）、C（类别数）、K、M 可以系统性地扫描"SSL 何时有益/有害"，并且可以**故意违反簇假设**（把 $\pi_i$ 设为极端不平衡、或让类条件分布严重重叠）来复现 Survey 的"No free lunch"警告。
* 输出真值 $(\pi_i, A_i, g_i, b_i, \sigma_i)$，用于机制分析。

**这套设计能回答的、当前水质数据回答不了的问题**：
1. 第三段的增益是否 $\propto$ "无标签数据对任务参数的信息量"？（在 $A_i$ 共享 vs 任务特异的两个版本上对比，预期：共享时 LP 无增益，任务特异时增益显著。）
2. 内循环 SSL 的伤害是否如实验 1b 所示随 $\alpha m$ 增大而急剧上升？那个"安全区"边界（$\alpha m\lesssim0.1\text{–}0.3$）在真实数据与不同任务参数信息量下是否移动？
3. OOD 比例 $\rho$ 升高时，后置 LP 与内循环 SSL 谁的鲁棒性更好？
4. 当簇假设被违反时（$\pi_i$ 极端不平衡、类条件分布严重重叠），第三段是否由"增益"翻转为"损害"？—— 这是 Survey "No free lunch" 警告的直接检验。

### 5.4 评测协议模板（建议写进论文）

```
对每个方法报告一张 5 元组表：
  方法 | 标签数 K | 无标签数 M | 直推/归纳 | 无标签前向次数 | 指标(均值±标准误)
必须同时给出：
  (a) 只用 K 个标签的纯监督基线；
  (b) random-init + 同一 SSL 阶段；
  (c) raw-input + 同一 SSL 阶段；
  (d) oracle（该任务的全部标签）。
并固定 episode 采样种子，所有方法共享同一批 episode（本工作在早期版本中因为 RNG 未重置导致方法间任务不同，方差被严重高估——这是一个很容易犯的错误）。
```

## 6. 研究定位与可发表的切入点

综合 §2 的机理与 §3 的结果，下面三个切入点有清晰的空白与可验证的预言：

**(1) "SSL 作为元正则 vs 作为适应算子"的分离研究。**
本工作已观察到：熵最小化放进**元训练目标**提升初始化（+3.58），放进**内循环适应**掉点（−12.81）。据文献检索，尚无工作系统区分这两个位置。可写成：给定固定的无标签预算，SSL 项应该注入 (a) 内循环、(b) 外循环、(c) 适应之后，三者的受控对比 + 一个说明何时该选哪个的判据。

**(2) 内循环 SSL 的"安全区"及其越界机制。**
本工作实验 1b 给出了一个干净的定量事实：内循环 SSL 的影响随 $\alpha m$ 从一个 ±1 点的"死区"跳变到 −23 点的强损害区。由此产生的可写问题是：(i) 这个边界能否用一个显式判据刻画（例如"SSL 项在支持集损失梯度方向的投影"与"该方向对 query 的收益"之比）？(ii) 能否设计一个**自适应开关**——在小 $\alpha m$ 下自动关闭、在检测到退化解风险时也关闭、只在中间区间生效？这比"再试一个 SSL 损失函数"更有价值。

**(3) 面向"无标签携带任务参数"的半监督元学习基准（§5.3 数据集 B）。**
当前 few-shot SSL 基准（Omniglot/miniImageNet）中无标签数据是否携带任务参数是不受控的，导致结论不可迁移。构建可控的基准本身就是一个可发表的工作，而且能同时服务时空预测领域。

**不建议的方向**：直接把 FixMatch 塞进 MAML 内循环。§1.2 与 §2 的预算分析表明，这条路线在样本量上差 6 个数量级，即便工程上跑通，也只能得到"损失函数形式"的收益而拿不到"伪标签课程"的收益。

| # | 实验 | 为什么值得做 | 预期 |
|---|---|---|---|

### 7.4 本工作的已知局限（应写进论文 limitation）

1. **合成任务族是自造的**，用来隔离"表示是否必需"这一变量；在真实图像 few-shot 基准（miniImageNet/tieredImageNet）上未验证。§5.3 的数据集 B 建议正是为了弥补这一点。
2. **直推口径**：实验一的 `sup_then_lp` 使用 query 的输入。作为对照，同一信息访问权下的内循环 SSL 变体全部 ≤79.44%，因此"后置优于内置"的结论不受影响；但"后置 +6.78"这一数字在**归纳口径**下不成立（需要 `unlabeled ∩ query = ∅` 的实验，尚未做）。
3. **未复现 Ren et al. 2018 的 soft k-means**（本工作只测了"原型蒸馏进梯度内循环"这一变体，属 M6 判据中的反例）。要完整支持 M6，需要实现 metric-based 流水线里的闭式 soft k-means 精修作为对照。
4. **水质实验只有 37 个站点**，元测试集仅 12 个（空间划分下 9 个）站点，标准误约 0.05–0.11；且随机/空间划分各只做了一次。跨区域下第三段的 −11.5% 需要多划分重复确认（见 §4.4 第 3 点的注记）。
5. **文献检索不完整**：TIM / LaplacianShot / PT-MAP / Simple CNAPS 与"时空 MAML"两块在本次检索中未取得可核验数据；PLATINUM（ICML 2022）的完整数值未核验。本文对这些工作的描述仅到"存在且方向相关"的程度，不应被引用为具体结论。
6. **实验 1b 的"冻结教师"基线是在同一个主干上做的**，其绝对水平的解读需要谨慎（它更像是一个机制探针，而不是一个可部署的方法）。

## 附录 A · 关键公式速查

**MAML 元目标**
$$\min_\theta\ \sum_{T_i\sim p(\mathcal T)} L_{T_i}\big(f_{\theta'_i}\big),\qquad \theta'_i=\theta-\alpha\nabla_\theta L_{T_i}(f_\theta),\qquad \theta\leftarrow\theta-\beta\nabla_\theta\sum_i L_{T_i}(f_{\theta'_i})$$

**元梯度（二阶）**
$$\nabla_\theta L_{T_i}(f_{\theta'_i})=\Big(I-\alpha\nabla^2_\theta L_{T_i}(f_\theta)\Big)^{\!\top}\nabla_{\theta'}L_{T_i}(f_{\theta'})=\nabla_{\theta'}L_{T_i}(f_{\theta'})-\alpha\,\mathrm{HVP}$$

**内循环注入 SSL**
$$\theta'_i=\theta-\alpha\nabla_\theta\big[L_S(\theta;D)+{\lambda}L_U(\theta;D_U)\big]$$

**硬钳制标签传播（回归用；闭式调和解）**
$$Y^{(t+1)}=SY^{(t)},\quad S=D^{-1/2}WD^{-1/2},\quad Y^{(t+1)}[L]=Y^{(0)}[L]$$
其中 $W$ 为 kNN-RBF 亲和矩阵。**不要用带 $(1-\alpha)Y_0$ 收缩项的 label spreading 做回归**：未标注节点的先验为 0 会造成致命收缩（本工作实测预测标准差 0.02 vs 真值 0.52）。

**图-Laplacian 流形正则（回归的可微 SSL 项）**
$$L_U(f)=\frac{f^\top L f}{\sum_{ij}|L_{ij}|},\qquad \frac{\partial L_U}{\partial f}=\frac{2Lf}{\sum_{ij}|L_{ij}|}$$

**FixMatch 无监督损失**
$$l_u=\frac{1}{\mu B}\sum_{b}\mathbb 1\big(\max(q_b)\ge\tau\big)H\big(\hat q_b,\ p_\theta(y|A(u_b))\big),\quad q_b=p_\theta(y|\alpha(u_b))$$
